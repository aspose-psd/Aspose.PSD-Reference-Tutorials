# تدوير الصورة بأي زاوية في Java – معالجة صور متقدمة

## مقدمة

إذا كنت تبحث عن حل **rotate image any angle** يجمع بين السرعة والدقة والاحتفاظ الكامل بملفات PSD، فإن Aspose.PSD for Java هو الجواب. في هذا الدليل سنستعرض سلسلة من الدروس المركزة — من تدوير الصور إلى استبدال الخطوط، وتطبيق إعادة التحجيم البيكوبيكي، وضغط ملفات GIF — حتى تتمكن من بناء خطوط معالجة صور قوية دون التضحية بالجودة. سواء كنت تحتاج إلى تدوير صورة بزاوية 45 درجة، أو تطبيق مرشح إعادة تحجيم مخصص، أو تحسين ملفات GIF المتحركة للويب، يغطي هذا الدليل كل خطوة.

```java
// Rotate a PSD image by 45 degrees using Aspose.PSD for Java
Image image = Image.load("input.psd");
image.rotate(45.0);
image.save("output.psd");
```

`Image` هي الفئة التي تمثل مستندًا نقطيًا أو PSD يمكن التلاعب به باستخدام Aspose.PSD. طريقة `rotate(double angle)` تدور الصورة بالزاوية المحددة مع الحفاظ على بيانات الطبقات.

```java
// Rotate a PSD image by 45 degrees using Aspose.PSD for Java
Image image = Image.load("input.psd");
image.rotate(45.0);
image.save("output.psd");
```

## إجابات سريعة
- **ما هي أسهل طريقة لتدوير صورة في Java؟** استخدم طريقة `Image.rotate()` من Aspose.PSD لتدوير بدون فقدان في سطر واحد من الشيفرة.  
- **هل يمكنني تدوير صورة بزاوية محددة؟** نعم – المكتبة تدعم الزوايا العشوائية عبر التحميل الزائد `rotate(double angle)`.  
- **هل أحتاج إلى ترخيص للاستخدام في الإنتاج؟** يلزم الحصول على ترخيص تجاري لـ Aspose.PSD للنشر غير التجريبي.  
- **هل استبدال الخطوط ممكن دون تعديل PSD يدويًا؟** بالتأكيد – توفر Aspose.PSD واجهة برمجة تطبيقات برمجية لاستبدال الخطوط في الصور.  
- **ما نسخة Java المدعومة؟** يعمل Aspose.PSD for Java مع Java 8 وما بعدها.

## ما هو “كيفية تدوير الصورة” في Java؟

`PsdImage` هي الفئة في Aspose.PSD التي تقوم بتحميل ملفات PSD للتلاعب بها. حمّل ملف PSD باستخدام `PsdImage` واستدعِ طريقة `rotate(double angle)` الخاصة به — هذه الطريقة تدور الصورة بالزاوية المحددة بالدرجات مع الحفاظ على كل طبقة، قناع، وتأثير تعديل. العملية تعيد توجيه بيانات البت ماب بدون فقدان، لذا يبقى الناتج البصري مطابقًا للتركيب الأصلي.

## لماذا تستخدم Aspose.PSD لتدوير الصور والمهام المتقدمة الأخرى؟

توفر Aspose.PSD تدويرًا حقيقيًا بدون فقدان، مما يعني أن بيانات البكسل لا تُعاد ترميزها أبدًا، وتدعم أكثر من 50 تنسيق إدخال وإخراج مع معالجة ملفات PSD تصل إلى 500 صفحة في أقل من 5 ثوانٍ على خادم بثمانية أنوية. يقلل التخزين المؤقت المدمج من استهلاك الذاكرة حتى 70 %، مما يجعلها أكثر مكتبة معالجة صور Java أداءً للعبء المؤسسي.

## كيفية استبدال الخطوط في الصور

`FontResource` هو الكائن في Aspose.PSD الذي يمثل خطًا مدمجًا داخل ملف PSD. تستبدل الخطوط بتحميل PSD باستخدام `PsdImage`، واستدعاء `getFontResources()`، وتحديد `FontResource` المستهدف، ثم استدعاء `setFont(new Font("Arial"))`. ينتقل التغيير إلى جميع طبقات النص التي تشير إلى ذلك الخط، مما يلغي التعديلات اليدوية ويحافظ على التخطيط. يضمن ذلك تناسق الطباعة عبر المستند بأكمله دون خطوات معالجة إضافية.

## إعادة تحجيم الصورة بنسبة متناسبة في Java

## تدوير الصورة بزاوية محددة في Java

`rotate(double)` هي الطريقة في Aspose.PSD التي تدور الصورة بأي زاوية تحددها. عندما يتطلب التصميم تدويرًا غير قياسي، يوضح دليل “Rotate Image on a Specific Angle” كيفية تمرير أي زاوية عائمة إلى طريقة `rotate(double)`. يشرح الدليل كيف تتعامل المكتبة مع استيفاء البكسل، وتحافظ على دقة الطبقات، وتحدّث حجم القماش لاستيعاب الاتجاه الجديد، مما يوفر نتيجة سلسة وبدون فقدان.
