# كيفية رسم إهليلج باستخدام الرسومات في Java مع Aspose.PSD

## مقدمة
في هذا الدرس المتعلق بالرسومات في Java ستكتشف **كيفية رسم إهليلج** وأشكال أخرى برمجيًا باستخدام Aspose.PSD for Java. سواء كنت بحاجة إلى إنشاء صور مصغرة ديناميكية، أو إنشاء عناصر واجهة مستخدم مخصصة، أو أتمتة سير عمل التصميم، فإن إتقان رسم الإهليلج وتعبئة التدرجات يمنحك تحكمًا بصريًا دقيقًا. الخطوات أدناه ترشدك إلى تهيئة الرسومات، ضبط الأقلام والفرش، وتصدير النتيجة بصيغ الصور الشائعة.

## إجابات سريعة
- **ما المكتبة المطلوبة؟** Aspose.PSD for Java (download from the official site).  
- **ما الشكل الذي يركز عليه الدرس؟** رسم إهليلج وتعبئة مضلع.  
- **هل يمكنني التصدير إلى صيغ غير BMP؟** نعم – PNG، JPEG، TIFF، وأكثر مدعومة.  
- **هل أحتاج إلى ترخيص للتطوير؟** ترخيص مؤقت مجاني يعمل للاختبار؛ ترخيص كامل مطلوب للإنتاج.  
- **هل الـ API مناسب للصور الكبيرة؟** Aspose.PSD يعالج ملفات حتى 500 MB دون تحميل كامل البت ماب في الذاكرة.

## كيفية رسم إهليلج في Java؟
حمّل `PsdImage` بالعرض والارتفاع المطلوبين، أنشئ كائن `Graphics`، اضبط `Pen`، واستدعِ `drawEllipse` مع مستطيل حد. العملية بأكملها تتطلب عددًا قليلًا من استدعاءات الطريقة وتنفّذ في أقل من ثانية للصور النموذجية 800×600 على أجهزة حديثة.

## ما هو Aspose.PSD for Java؟
Aspose.PSD for Java هو **مكتبة pure‑Java توفر أكثر من 50 تحويل صيغة صورة وإمكانيات تحرير PSD كاملة** دون الحاجة إلى Adobe Photoshop. يمكنه عرض، تعديل، وتصدير ملفات متعددة الطبقات مع الحفاظ على استهلاك الذاكرة منخفضًا، مما يجعله مثاليًا لتوليد الرسومات على الخادم.

## لماذا نستخدم Aspose.PSD لرسم الأشكال؟
Aspose.PSD يقدم أداءً عاليًا، دعمًا واسعًا للصيغ، وعرضًا دقيقًا، مما يجعله مثاليًا لتوليد الرسومات على الخادم ورسم الأشكال المعقدة.

- **الأداء:** يتعامل مع صور حتى 500 MB باستخدام أقل من 150 MB من الذاكرة (≈30 % أقل من المكتبات المنافسة).  
- **دعم الصيغ:** أكثر من 50 صيغة إدخال وإخراج، بما في ذلك BMP، PNG، JPEG، TIFF، وPSD.  
- **الدقة:** عرض تحت‑بكسلي يضمن إهليلجات حادة وتدرجات ناعمة على شاشات عالية الـ DPI.

## استيراد الحزم
لبدء العمل، استورد الفئات الضرورية من Aspose.PSD وأدوات Java القياسية. الفئات التالية توفر بدائيات الرسم ومعالجة الألوان:
```java
import com.aspose.psd.Color;
import com.aspose.psd.Graphics;
import com.aspose.psd.Pen;
import com.aspose.psd.Point;
import com.aspose.psd.Rectangle;
import com.aspose.psd.brushes.LinearGradientBrush;
import com.aspose.psd.fileformats.psd.PsdImage;
import com.aspose.psd.imageoptions.BmpOptions;
```

## الخطوة 1: إنشاء كائن صورة
`PsdImage` يمثل لوحة رستر في الذاكرة يمكن الرسم عليها وحفظها بصيغ متعددة.
```java
String dataDir = "Your Document Directory";
PsdImage image = new PsdImage(500, 500);
```

## الخطوة 2: تهيئة كائن الرسومات
`Graphics` هو سطح الرسم المرتبط بـ `PsdImage`، يتيح عمليات متجهية مثل رسم الأشكال.
```java
Graphics graphics = new Graphics(image);
```

## الخطوة 3: مسح سطح الصورة
`clear` يملأ كامل اللوحة بلون خلفية موحد.
```java
graphics.clear(Color.getWhite());
```

## الخطوة 4: إنشاء وتكوين كائن القلم
`Pen` يحدد لون الحد، عرضه، والنمط المستخدم عند رسم الخطوط.
```java
Pen pen = new Pen(Color.getBlue());
```

## الخطوة 5: رسم الأشكال
`drawEllipse` يرسم إهليلجًا يتناسب داخل المستطيل المحدد باستخدام القلم الحالي.
```java
graphics.drawEllipse(pen, new Rectangle(10, 10, 150, 100));
```

## الخطوة 6: استخدام الفُرش للتعبئة
`LinearGradientBrush` ينشئ تعبئة متدرجة تنتقل بين لونين عبر مساحة محددة.
```java
LinearGradientBrush linearGradientBrush = new LinearGradientBrush(image.getBounds(), Color.getRed(), Color.getWhite(), 45f);
Point[] points = { new Point(200, 200), new Point(400, 200), new Point(250, 350) };
graphics.fillPolygon(linearGradientBrush, points);
```

## الخطوة 7: حفظ الصورة المعدلة
`save` يكتب `PsdImage` إلى القرص بالصيغ المختارة، مثل BMP أو PNG.
```java
image.save(dataDir + "DrawingUsingGraphics_output.bmp", new BmpOptions());
```

## مشكلات شائعة وحلول
- **NullPointerException على الرسومات:** تأكد من أن `PsdImage` تم إنشاؤه بالكامل قبل إنشاء كائن `Graphics`.  
- **ألوان غير صحيحة:** استخدم `Color.fromArgb` لتحديد قيم ARGB الدقيقة عندما لا يتطابق اللوح الافتراضي مع التوقعات.  
- **تأخر الأداء على الصور الكبيرة:** فعّل `PsdImageOptions` مع `compression = CompressionType.Rle` لتقليل استهلاك الذاكرة.
