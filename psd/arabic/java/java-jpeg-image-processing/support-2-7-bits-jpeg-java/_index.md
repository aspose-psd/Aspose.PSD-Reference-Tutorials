# دليل معالجة الصور بجافا: دعم JPEG بعمق 2‑ و 7‑بت

## مقدمة
في هذا **java image processing tutorial**، ستكتشف كيفية استخدام مكتبة Aspose.PSD for Java لتحميل ملف PSD وتصديره كـ JPEG بعمق 2‑ أو 7‑بت. سواء كنت تبني خدمة تحويل دفعي أو تحتاج إلى تحكم دقيق في جودة الصورة، فإن الخطوات أدناه ستقودك من إعداد البيئة إلى حفظ JPEG النهائي. هيا نبدأ!

## إجابات سريعة
- **أي مكتبة تتعامل مع JPEG بعمق 2‑ و 7‑بت؟** Aspose.PSD for Java.  
- **الحد الأدنى لإصدار Java؟** JDK 8 أو أعلى.  
- **هل أحتاج إلى ترخيص للتطوير؟** نسخة تجريبية مجانية تكفي للتقييم؛ يلزم ترخيص تجاري للإنتاج.  
- **هل يمكنني تغيير وضع اللون؟** نعم – يدعم CMYK و YCCK وغيرها عبر `JpegCompressionColorMode`.  
- **ما مقدار تقليل حجم الملف الذي يمكن توقعه؟** استخدام 2‑بت لكل قناة يمكن أن يقلص JPEG بنسبة تصل إلى 80 % مقارنة بالإخراج 8‑بت.

## ما هو دليل معالجة الصور بجافا؟
دليل معالجة الصور بجافا هو دليل خطوة بخطوة يعلّم المطورين كيفية معالجة بيانات الصورة برمجيًا باستخدام Java. يغطي تحميل صيغ متعددة، تطبيق التحويلات، تعديل إعدادات اللون والضغط، وحفظ النتائج، مما يتيح لك بناء سير عمل مخصص لمعالجة الصور.

## لماذا تستخدم Aspose.PSD for Java؟
Aspose.PSD for Java توفر API شاملة للعمل مع ملفات Photoshop دون الحاجة إلى Photoshop نفسه. تدعم أكثر من 30 صيغة صورة، تتعامل مع ملفات تصل إلى 2 GB عبر تدفق البيانات، وتوفر تحكمًا دقيقًا في الطبقات والقنوات وملفات تعريف الألوان، مما يجعلها مثالية للمعالجة عالية الأداء على الخادم.

## المتطلبات المسبقة
قبل البدء، تأكد من وجود ما يلي:

1. **Java Development Kit (JDK)** – الإصدار 8 أو أعلى.  
2. **Aspose.PSD for Java library** – يمكنك [download it here](https://releases.aspose.com/psd/java/).  
3. **IDE** – IntelliJ IDEA أو Eclipse أو NetBeans.  
4. **Sample PSD file** – أي ملف PSD ترغب في تحويله.  
5. **Basic Java knowledge** – الإلمام بالفئات والكائنات ومعالجة الاستثناءات.

## استيراد الحزم
أولاً، أضف ملف Aspose.PSD JAR إلى مسار الفئة (classpath) في مشروعك. ثم استورد المساحات الاسمية المطلوبة:

```java
import com.aspose.psd.Image;
import com.aspose.psd.fileformats.jpeg.JpegCompressionColorMode;
import com.aspose.psd.fileformats.jpeg.JpegCompressionMode;
import com.aspose.psd.fileformats.psd.PsdImage;
import com.aspose.psd.imageoptions.JpegOptions;
```

## كيفية تحميل صورة PSD في Java؟
لتحميل ملف PSD، استدعِ الطريقة الساكنة `load` من الفئة `Image` وقم بتحويل النتيجة إلى `PsdImage`. هذا ينشئ تمثيلًا في الذاكرة لوثيقة Photoshop، مما يمنحك الوصول إلى طبقاتها وقنواتها وأقنعتها وبيانات التعريف الخاصة بها، والتي يمكنك بعد ذلك تعديلها أو تصديرها إلى صيغ أخرى.

`PsdImage` هي الفئة الأساسية في Aspose.PSD التي تمثل وثيقة Photoshop في الذاكرة، وتتيح عمليات القراءة والكتابة على محتواها.

```java
String dataDir = "Your Document Directory";
PsdImage image = (PsdImage) Image.load(dataDir + "PsdImage.psd");
```

## كيفية تكوين خيارات JPEG للإخراج بعمق 2‑ أو 7‑بت؟
أنشئ كائنًا جديدًا من `JpegOptions` واضبط خصائصه لتتناسب مع الإخراج المطلوب. استخدم `setColorType` لاختيار `JpegCompressionColorMode` المناسب (مثل CMYK أو YCCK)، واستخدم `setCompressionType` لتحديد خوارزمية الضغط. أخيرًا، عيّن قيمة `bitsPerChannel` (2 أو 7) للتحكم في عمق البت لكل قناة لون.

```java
JpegOptions options = new JpegOptions();
options.setColorType(JpegCompressionColorMode.Cmyk);
options.setCompressionType(JpegCompressionMode.JpegLs);
```

## كيفية ضبط عدد البتات لكل قناة لصور JPEG منخفضة البت؟
`bitsPerChannel` يحدد عدد البتات المستخدمة لكل قناة لون في JPEG الناتج. ضبط هذه الخاصية على 2 يقلل كل قناة إلى بتين، مما ينتج صورة مضغوطة بشدة مع ظهور تدرجات ملحوظة، بينما القيمة 7 تحتفظ بمزيد من التفاصيل وتنتج حجم ملف بين النتيجتين منخفضة البت والقياسية 8‑بت. اختر القيمة التي توازن بين الجودة والحجم وفقًا لحالتك.

```java
byte bpp = 2;
options.setBitsPerChannel(bpp);
```

## كيفية تطبيق ملفات تعريف الألوان (اختياري)؟
`ICCProfile` يمثل ملف تعريف من International Color Consortium يصف خصائص اللون لجهاز أو مساحة عمل. إذا كان لديك ملف ICC مخصص، حمّله باستخدام `ICCProfile.getInstance(path)` وعيّنه إلى خاصية `iccProfile` في كائن `jpegOptions`. ترك الخاصية فارغة (null) يجعل Aspose.PSD يستخدم ملف التعريف الافتراضي للنظام، وهو مناسب لمعظم السيناريوهات.

```java
options.setRgbColorProfile(null);
options.setCmykColorProfile(null);
```

## كيفية حفظ الصورة المعالجة كملف JPEG؟
طريقة `save` تكتب الصورة إلى ملف باستخدام الخيارات المقدمة. استدعها على كائن `PsdImage`، مع تمرير اسم الملف الهدف (متضمنًا امتداد .jpg) و`JpegOptions` المكوَّنة. المكتبة تتولى الترميز، وتطبيق عدد البتات لكل قناة وملف تعريف اللون المختار، وتنتج JPEG يطابق مواصفاتك.

```java
image.save(dataDir + "2_7BitsJPEG_output.jpg", options);
```

## المشكلات الشائعة والحلول
- **File too large error** – تأكد من أنك تستخدم أحدث نسخة من Aspose.PSD، التي تقوم بتدفق البيانات وتجنب تحميل الملف بالكامل إلى الذاكرة.  
- **Unexpected colors** – تحقق من أن `JpegCompressionColorMode` المختار يتطابق مع مساحة ألوان الصورة المصدر.  
- **Missing ICC profile** – إذا كنت بحاجة إلى ملف تعريف محدد، حمّله باستخدام `ICCProfile.getInstance(path)` وعيّنه إلى `JpegOptions`.
