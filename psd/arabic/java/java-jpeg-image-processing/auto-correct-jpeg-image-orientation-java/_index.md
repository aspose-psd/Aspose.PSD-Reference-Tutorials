# تصحيح تلقائي لتوجيه صورة JPEG في Java

في عصرنا الرقمي اليوم، أصبح التلاعب بالصور وتحسينها برمجيًا مهمة حاسمة للمطورين عبر مختلف المجالات. **Auto correct JPEG orientation** هو طلب شائع عند التعامل مع الصور الملتقطة على أجهزة مختلفة. تمكّنك Aspose.PSD for Java من أدوات قوية للتعامل مع ملفات PSD و JPEG وغيرها من تنسيقات الصور بكفاءة. يغوص هذا الدرس في مهمة محددة: تصحيح توجيه صورة JPEG تلقائيًا باستخدام Aspose.PSD for Java. سواء كنت تبني تطبيق تحرير صور، أو تدير موارد الصور في نظام إدارة محتوى، أو تقوم بأتمتة خطوط معالجة الصور، ستتعلم كيفية دمج هذه القدرة بسلاسة.

## ما هو تصحيح تلقائي لتوجيه JPEG؟
تصحيح تلقائي لتوجيه JPEG هو الكشف الآلي عن علامة “Orientation” في بيانات EXIF للصورة ثم تدوير البت ماب بحيث تظهر بصورة صحيحة دون تدخل يدوي. يقرأ هذا العملية البيانات الوصفية المدمجة في ملف JPEG، يحدد الدوران أو الانعكاس المطلوب، ويطبق التحويل بحيث يتطابق العرض البصري مع نية المصور عبر جميع منصات العرض.

## لماذا نستخدم Aspose.PSD لتصحيح توجيه JPEG تلقائيًا؟
يدعم Aspose.PSD **أكثر من 30 تنسيق صورة** ويمكنه معالجة ملفات تصل إلى **2 GB** دون تحميل الصورة بالكامل إلى الذاكرة، مما يقدّم أداءً أسرع حتى **5×** مقارنةً بالتدوير اليدوي بكسل بكسل على عتاد مماثل. كما يتعامل المكتبة مع الموارد المدمجة، مثل صور JPEG المصغرة داخل ملفات PSD، وتوفر واجهات برمجة تطبيقات عالية المستوى تُجرد من تحليل EXIF منخفض المستوى، مما يجعل التنفيذ بسيطًا وموثوقًا.

## استيراد الحزم
قبل البدء بالمثال، تأكد من استيراد الحزم اللازمة من Aspose.PSD for Java. فئة `Image` هي النوع الأساسي لتحميل وحفظ الصور، بينما توفر `JpegExifData` الوصول إلى بيانات EXIF الوصفية، وتمثل فئات موارد الصورة المصغرة معاينات JPEG المدمجة.  

```java
import com.aspose.psd.Image;
import com.aspose.psd.exif.JpegExifData;
import com.aspose.psd.fileformats.psd.PsdImage;
import com.aspose.psd.fileformats.psd.resources.Thumbnail4Resource;
import com.aspose.psd.fileformats.psd.resources.ThumbnailResource;
```

## كيفية تصحيح توجيه JPEG تلقائيًا باستخدام Aspose.PSD في Java؟
حمّل ملف PSD المستهدف، حدد موقع الصورة المصغرة JPEG المدمجة، دع Aspose.PSD يقرأ توجيه EXIF الخاص بها، طبّق التدوير التلقائي، وأخيرًا احفظ الصورة المصححة. يتطلب هذا سير العمل فقط بضع استدعاءات للطرق ويعمل مع أي صورة JPEG مدمجة في حاوية PSD، مما يجعله مناسبًا لكل من سيناريوهات الصورة الفردية ومعالجة الدفعات.

## الخطوة 1: تحميل صورة PSD
تمثل فئة `PsdImage` ملف PSD وتوفر الوصول إلى موارده، بما في ذلك الصور المصغرة JPEG المدمجة.  
أولاً، حمّل صورة PSD التي تحتوي على الصورة المصغرة JPEG التي يحتاج توجيهها إلى تصحيح:

```java
String dataDir = "Your Document Directory";
PsdImage image = (PsdImage)Image.load(dataDir + "1280px-Zebras_Serengeti.psd");
```
استبدل `"Your Document Directory"` بالمسار الفعلي للمجلد حيث يقع ملف PSD الخاص بك.

## الخطوة 2: التكرار عبر موارد الصورة
بعد ذلك، قم بالتكرار عبر موارد الصورة للعثور على مورد الصورة المصغرة JPEG. تمثل `ThumbnailResource` و `Thumbnail4Resource` إصدارات مختلفة من معاينات JPEG المدمجة داخل ملف PSD.

```java
for (int i = 0; i < image.getImageResources().length; i++) {
    // Find thumbnail resource. Typically they are in the Jpeg file format.
    if (image.getImageResources()[i] instanceof ThumbnailResource || image.getImageResources()[i] instanceof Thumbnail4Resource) {
        // Adjust thumbnail data.
        ThumbnailResource thumbnail = (ThumbnailResource) image.getImageResources()[i];
        JpegExifData exifData = thumbnail.getJpegOptions().getExifData();
        if (exifData != null && exifData.getThumbnail() != null) {
            // If there is a thumbnail stored, auto-rotate it.
            PsdImage jpegImage = (PsdImage) exifData.getThumbnail();
            if (jpegImage != null) {
                jpegImage.autoRotate();
            }
        }
    }
}
```

## الخطوة 3: حفظ الصورة
أخيرًا، احفظ الصورة المصححة بعد تطبيق التدوير التلقائي:

```java
image.save();
```
تضمن هذه الخطوة أن التغييرات التي أجريت على الصورة تُحفظ.

## المشكلات الشائعة واستكشاف الأخطاء
- **EXIF tag not detected** – تأكد من أن الصورة المصغرة JPEG تحتوي فعليًا على علامة Orientation؛ بعض الكاميرات قد تحذفها.  
- **Memory errors on large files** – استخدم `PsdImage.load(..., LoadOptions)` مع `LoadOptions.setLoadAllResources(false)` للحفاظ على استهلاك الذاكرة منخفضًا.  
- **Incorrect rotation direction** – تأكد من أنك تستخدم أحدث إصدار من Aspose.PSD؛ الإصدارات القديمة كان فيها خطأ معروف مع بعض قيم التوجيه.
