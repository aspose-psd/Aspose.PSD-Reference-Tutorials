## فلتر خطوة بخطوة: كيفية تطبيق مرشح Median

يقوم مرشح Median بإزالة **salt‑and‑pepper noise** مع الحفاظ على حدة الحواف. يعمل عن طريق تمرير نافذة فوق كل بكسل واستبدال القيمة المركزية بمتوسط القيم المحيطة، مما يلغي القيم المتطرفة دون تمويه التفاصيل المهمة.

### الخطوة 1: تحميل الصورة

```java
import com.aspose.psd.Image;
import com.aspose.psd.RasterImage;

import com.aspose.psd.imagefilters.filteroptions.MedianFilterOptions;
import com.aspose.psd.imageoptions.GifOptions;
```

### الخطوة 2: تحويل Image إلى RasterImage

```java
String dataDir = "Your Document Directory";
String sourceFile = dataDir + "sample.psd";

// Load the source image
Image image = Image.load(sourceFile);
```

### الخطوة 3: إنشاء كائن MedianFilterOptions

```java
// Cast the image into RasterImage
RasterImage rasterImage = (RasterImage)image;
if (rasterImage == null) {
    return;
}
```

### الخطوة 4: تطبيق مرشح Median

```java
// Create an instance of MedianFilterOptions class and set the filter size
MedianFilterOptions options = new MedianFilterOptions(4);
```

### الخطوة 5: حفظ الصورة الناتجة (تحويل PSD إلى GIF)

`GifOptions` يحدد الإعدادات لحفظ الصورة بصيغة GIF، مثل عمق اللون والضغط. `ExportFormat.Gif` هو قيمة الـ enum المستخدمة لحفظ الصورة كملف GIF.

```java
// Apply MedianFilterOptions filter to RasterImage object
rasterImage.filter(image.getBounds(), options);
```

باتباع هذه الخطوات تكون قد طبقت بنجاح مرشح Median وصدّرت الصورة المنقاة كملف GIF.

## تطبيق مرشح Wiener (امتداد اختياري)

يقوم مرشح Wiener بتقليل الضوضاء التكيفي عن طريق تقدير التباين المحلي، مما يجعله مثاليًا للصور ذات مستويات ضوضاء متغيرة. استبدل مرشح Median بـ `WienerFilterOptions` واحتفظ بنفس سير العمل.

> **نصيحة محترف:** جرّب أحجام نوى مختلفة لكلا الفلترين للعثور على النقطة المثالية بين إزالة الضوضاء والحفاظ على التفاصيل.
