## What is an EXIF thumbnail?
An EXIF thumbnail is a small, low‑resolution image stored inside the EXIF metadata block of a JPEG file. It allows quick preview generation in file browsers and digital asset management tools. Typically sized around 160 × 120 pixels, the thumbnail provides a visual cue without loading the full‑resolution image, reducing bandwidth and improving performance.

PsdImage is Aspose.PSD’s class for loading an image file; use `new PsdImage("input.jpg")` to open the JPEG. Create a Thumbnail (a small preview image) from a Bitmap or byte array, assign it to `ExifData.Thumbnail`, and save. The library updates related tags such as `ExifTag.ThumbnailLength` and `ExifTag.ThumbnailOffset` automatically.
