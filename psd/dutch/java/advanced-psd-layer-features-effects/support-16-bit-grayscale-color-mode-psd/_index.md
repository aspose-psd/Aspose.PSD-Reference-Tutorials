# Export PSD als PNG met 16‑bit grijswaarden kleurenmodus in Java

## Inleiding
Het exporteren van PSD als PNG terwijl je een 16‑bit grijswaarden kleurenmodus behoudt, geeft je de diepte van een professionele foto en de universele compatibiliteit van PNG. In deze gids leer je hoe je **de PSD‑kleurenmodus instelt op 16‑bit grijswaarden** en vervolgens **de PSD exporteert als PNG** met Aspose.PSD voor Java. De tutorial behandelt alles van vereisten tot probleemoplossing, zodat je de workflow kunt integreren in elke Java‑gebaseerde afbeeldingspijplijn.

## Snelle antwoorden
- **Wat houdt “export PSD as PNG” in?** Laad een PSD, wijzig eventueel de kleurenmodus, en sla deze op als een PNG‑bestand.  
- **Welke Aspose‑klasse behandelt de conversie?** `PsdImage` laadt de PSD en `PngOptions` definieert de PNG‑uitvoersettings.  
- **Heb ik een licentie nodig voor productie?** Ja – een proefversie werkt voor testen, maar een betaalde licentie is vereist voor commercieel gebruik.  
- **Kan de 16‑bit diepte behouden blijven in PNG?** Absoluut, door `PngColorType.GrayscaleWithAlpha` te gebruiken.  
- **Welke IDE's worden ondersteund?** Elke Java‑IDE – IntelliJ IDEA, Eclipse, VS Code, of NetBeans.

## Wat is export PSD als PNG?
Export PSD as PNG is het proces van het converteren van een Adobe Photoshop‑document (PSD) naar een Portable Network Graphics (PNG)‑bestand, terwijl de pixelgegevens en kleurdiepte van de afbeelding behouden blijven. Deze conversie wordt vaak gebruikt om hoogwaardige grijswaarden‑assets op het web te delen zonder tonale details te verliezen.

## Waarom export PSD als PNG met 16‑bit grijswaarden?
Exporteren naar PNG terwijl 16‑bit grijswaarden behouden blijft, behoudt 65 536 grijstinten, wat veel meer tonale rijkdom biedt dan 8‑bit afbeeldingen. De universele ondersteuning van PNG zorgt ervoor dat de bestanden in browsers, mobiele apps en desktop‑editors kunnen worden weergegeven zonder verlies, terwijl de verliesvrije compressie van Aspose.PSD garandeert dat er geen artefacten worden geïntroduceerd.

## Hoe stel je de PSD‑kleurenmodus in op 16‑bit grijswaarden?
`PsdImage` is de Aspose.PSD‑klasse die een PSD‑bestand laadt en in het geheugen representeert.  
`ColorMode` is een enumeratie die de kleurenmodus van een PSD‑afbeelding definieert.

Laad de PSD met `PsdImage`, wijzig de kleurenmodus via de `ColorMode`‑eigenschap, en sla vervolgens het gewijzigde bestand op. Deze bewerking draait volledig in het geheugen, waardoor tussenbestanden overbodig zijn en de conversie snel en efficiënt verloopt.

```java
import com.aspose.psd.*;
import com.aspose.psd.fileformats.png.PngColorType;
import com.aspose.psd.fileformats.psd.ColorModes;
import com.aspose.psd.fileformats.psd.CompressionMethod;
import com.aspose.psd.fileformats.psd.PsdImage;
import com.aspose.psd.imageoptions.PngOptions;
import com.aspose.psd.imageoptions.PsdOptions;
import com.aspose.psd.system.Enum;
```

Deze imports geven je toegang tot de functionaliteiten die je gebruikt om PSD‑bestanden te manipuleren, de kleurenmodus in te stellen, en het resultaat als PNG te exporteren.

## Hoe laad je de PSD en pas je de 16‑bit grijswaardenmodus toe?
`PsdImage` is de Aspose.PSD‑klasse die een PSD‑bestand in het geheugen laadt.  
`ColorMode.GRAYSCALE_16` is een enumeratiewaarde die de afbeelding instelt op 16‑bit grijswaarden.  
`channelBitsCount` is een eigenschap die het aantal bits per kanaal specificeert.

Binnen de conversiemethode, bouw de volledige bestandspaden, instantiateer `PsdImage`, en wijzig zijn `ColorMode` naar `ColorMode.GRAYSCALE_16`. De eigenschap `channelBitsCount` moet op 16 worden gezet om de hoge bits‑diepte te behouden, zodat de afbeelding alle tonale informatie behoudt.

```java
String filePath = sourceDir + file + ".psd";
String postfix = Enum.getName(ColorModes.class, colorMode) + channelBitsCount + "_" +
                 channelsCount + "_" + Enum.getName(CompressionMethod.class, compression);
String exportPath = outputDir + file + postfix + ".psd";
String pngExportPath = outputDir + file + postfix + ".png";
// Load a predefined 16-bit grayscale PSD
PsdImage image = (PsdImage)Image.load(filePath);
```

De `postfix` helpt je bij het bijhouden van de instellingen die voor elk geëxporteerd bestand zijn gebruikt.

## Hoe sla je de gewijzigde PSD op met de nieuwe kleurenmodus?
`PsdOptions` is een klasse die regelt hoe een PSD‑bestand wordt opgeslagen, inclusief kleurenmodus en bits‑diepte‑instellingen.

Na het tekenen (of het overslaan van die stap), roep `save` aan op de `PsdImage`‑instantie, waarbij een `PsdOptions`‑object wordt doorgegeven dat de 16‑bit grijswaardenconfiguratie behoudt. Dit zorgt ervoor dat de opgeslagen PSD de gewenste kleurenmodus behoudt zonder gegevensverlies.

```java
    // Save a copy of PSD with specific characteristics
    PsdOptions psdOptions = new PsdOptions();
    psdOptions.setColorMode(colorMode);
    psdOptions.setChannelBitsCount(channelBitsCount);
    psdOptions.setChannelsCount(channelsCount);
    psdOptions.setCompressionMethod(compression);
    image.save(exportPath, psdOptions);
}
```

## Hoe converteer je de PSD naar PNG terwijl je de 16‑bit diepte behoudt?
`PngOptions` is een klasse die PNG‑uitvoersettingen definieert, zoals kleurtype en compressieniveau.  
`PngColorType.GrayscaleWithAlpha` is een enumeratiewaarde die 16‑bit grijswaarden‑data opslaat met een alfakanaal.

Laad de nieuw opgeslagen PSD, configureer `PngOptions` met `PngColorType.GrayscaleWithAlpha`, en roep `save` aan. Dit behoudt de 16‑bit grijswaarden‑data in het PNG‑bestand, waardoor een verliesvrije, hoogwaardige afbeelding ontstaat die geschikt is voor verdere verwerking of distributie.


## Veelvoorkomende problemen en oplossingen
| Probleem | Waarom het gebeurt | Oplossing |
|----------|--------------------|----------|
| **“Unsupported color type” exception** | Poging om een PSD op te slaan met een niet‑ondersteunde kanaalconfiguratie. | Zorg ervoor dat `channelBitsCount` overeenkomt met de werkelijke bits‑diepte (16) en dat `channelsCount` correct is voor grijswaarden (1). |
| **File not found** | Onjuist bronmappad. | Controleer de `sourceDir`‑string nogmaals en verifieer dat het PSD‑bestand op die locatie bestaat. |
| **Output PNG appears black** | PNG opgeslagen zonder correcte alfabehandeling. | Gebruik `PngColorType.GrayscaleWithAlpha` zoals hierboven getoond. |
| **Memory overflow on large PSDs** | Het volledige bestand in het geheugen laden. | Schakel streaming‑modus in via `PsdImage.load(inputStream, new LoadOptions())` om grote bestanden efficiënt te verwerken. |
