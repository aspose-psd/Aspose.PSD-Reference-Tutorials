# วิธีแปลง AI เป็น PSD ใน Java

## บทนำ
หากคุณต้องการ **วิธีแปลง AI** ไฟล์เป็นรูปแบบ Photoshop PSD จากแอปพลิเคชัน Java คุณมาถูกที่แล้ว ในบทแนะนำนี้เราจะพาคุณผ่านทุกขั้นตอน—การติดตั้งไลบรารี Aspose.PSD for Java, การโหลดไฟล์ Illustrator (.ai), การกำหนดค่าตัวเลือกการแปลง, และการบันทึก PSD ที่ได้ลงดิสก์ เมื่อเสร็จคุณจะสามารถทำให้กระบวนการแปลงเวกเตอร์เป็นแรสเตอร์อัตโนมัติ, สร้างภาพย่อ, หรือรวมทรัพยากร Illustrator เข้ากับเวิร์กโฟลว์กราฟิกฝั่งเซิร์ฟเวอร์โดยไม่ต้องเปิด Adobe Illustrator.

## คำตอบอย่างรวดเร็ว
- **ไลบรารีใดที่จัดการการแปลง?** Aspose.PSD for Java มี API แบบ pure‑Java ที่ไม่มีการพึ่งพา native ใด ๆ.  
- **ฉันสามารถรันนี้บนระบบปฏิบัติการใดก็ได้หรือไม่?** ใช่—แพลตฟอร์มใด ๆ ที่รองรับ Java 8+ จะทำงานได้ รวมถึง Windows, Linux และ macOS.  
- **ฉันต้องการใบอนุญาตสำหรับการพัฒนาหรือไม่?** ใบอนุญาตชั่วคราวของ Aspose จะยกเลิกข้อจำกัดการประเมิน; จำเป็นต้องมีใบอนุญาตเต็มสำหรับการใช้งานในสภาพแวดล้อมการผลิต.  
- **การแปลงเร็วแค่ไหน?** ไฟล์ทั่วไปที่มีขนาดต่ำกว่า 5 MB จะถูกแปลงในเวลา 30–70 ms บน CPU มาตรฐาน 2.5 GHz.  
- **ต้องการซอฟต์แวร์เพิ่มเติมหรือไม่?** ไม่จำเป็นต้องติดตั้ง Adobe Illustrator หรือ Photoshop.

## “convert ai psd” คืออะไร?
วลี **convert ai psd** หมายถึงการแปลงไฟล์เวกเตอร์ Adobe Illustrator (.ai) เป็นไฟล์แรสเตอร์ Adobe Photoshop (.psd) อย่างอัตโนมัติ ซึ่งทำให้สามารถสร้างกระบวนการออกแบบอัตโนมัติ, การสร้างภาพย่อจำนวนมาก, หรือการรวมทรัพยากรเวกเตอร์เข้าสู่ระบบที่ใช้แรสเตอร์โดยไม่ต้องทำขั้นตอนการส่งออกด้วยมือ.

## นำเข้าแพ็กเกจ
ขั้นตอนแรกคือทำให้คลาส Aspose.PSD พร้อมใช้งานในโปรเจกต์ของคุณ เพิ่ม JAR ไปยัง classpath ด้วยตนเอง, หรือรวมการพึ่งพา Maven ใน `pom.xml`.  
```java
import com.aspose.psd.Image;
import com.aspose.psd.fileformats.ai.AiImage;
import com.aspose.psd.imageoptions.PsdOptions;
```  
หรือคุณสามารถดาวน์โหลดไฟล์ JAR จาก [หน้าดาวน์โหลด Aspose.PSD for Java](https://releases.aspose.com/psd/java/) และเพิ่มลงในโปรเจกต์ของคุณด้วยตนเอง.  
เรามาแยกกระบวนการเป็นขั้นตอนง่าย ๆ ที่จัดการได้.

## ขั้นตอนที่ 1: ตั้งค่าโปรเจกต์ของคุณ
ขั้นแรก ตั้งค่าโปรเจกต์ Java ใหม่ใน IDE ของคุณ.

### สร้างโปรเจกต์ใหม่
1. เปิด IDE ของคุณและสร้างโปรเจกต์ Java ใหม่.  
2. ตั้งชื่อให้มีความหมาย เช่น **AItoPSDConverter**.  

### เพิ่มไลบรารี Aspose.PSD
1. หากคุณดาวน์โหลดไฟล์ JAR แล้ว, ให้เพิ่มเข้าไปในเส้นทางการสร้างของโปรเจกต์ผ่าน *Project → Properties → Libraries*.  
2. หากคุณใช้ Maven ให้เพิ่มการพึ่งพาต่อไปนี้ใน `pom.xml` (แทนที่เวอร์ชันด้วยเวอร์ชันล่าสุด):  

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-psd</artifactId>
    <version>24.12</version>
</dependency>
```

## ขั้นตอนที่ 2: โหลดไฟล์ AI
เมื่อไลบรารีอยู่ใน classpath แล้ว, คุณสามารถโหลดไฟล์ Illustrator ต้นฉบับได้.  
```java
String dataDir = "Your Document Directory"; 
String sourceFileName = dataDir + "34992OStroke.ai";       
AiImage image = (AiImage) Image.load(sourceFileName);
```  
คลาส `PsdImage` อ่านไฟล์ AI เข้าสู่หน่วยความจำ, คงข้อมูลเวกเตอร์ไว้สำหรับการแปลงต่อไป.

## ขั้นตอนที่ 3: ตั้งค่า PSD options
ก่อนบันทึก คุณอาจต้องการควบคุมโหมดสี, ความละเอียด, หรือการจัดการชั้น.  
```java
PsdOptions options = new PsdOptions();
```  
Aspose.PSD มีอ็อบเจกต์ `PsdOptions` ที่คุณสามารถระบุพารามิเตอร์เหล่านี้ได้.

## ขั้นตอนที่ 4: บันทึกไฟล์ AI เป็น PSD
สุดท้าย เขียนภาพที่แปลงแล้วลงดิสก์เป็นไฟล์ PSD.  
```java
String outFileName = dataDir + "34992OStroke.psd";
image.save(outFileName, options);
```  
เมธอด `save` จัดการรายละเอียดเฉพาะรูปแบบทั้งหมด, สร้างไฟล์ที่เข้ากันได้กับ Photoshop พร้อมสำหรับการแก้ไขต่อไป.
