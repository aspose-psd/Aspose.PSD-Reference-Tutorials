## Jak převést PSB na JPG v Javě?
**PsdImage** je třída Aspose.PSD, která představuje Photoshop dokument v paměti. **SaveFormat.Jpeg** je hodnota výčtu, která říká knihovně, aby zapsala obrázek jako JPEG soubor. Načtěte svůj PSB soubor pomocí `PsdImage` a zavolejte `save` s určením `SaveFormat.Jpeg`.
