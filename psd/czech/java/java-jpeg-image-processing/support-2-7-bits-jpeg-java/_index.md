# Java tutoriál zpracování obrazu: podpora 2‑ a 7‑bitových JPEG

## Úvod
V tomto **java tutoriálu zpracování obrazu** objevíte, jak použít knihovnu Aspose.PSD for Java k načtení souboru PSD a exportu jako 2‑ nebo 7‑bitový JPEG. Ať už vytváříte službu pro hromadnou konverzi nebo potřebujete jemnou kontrolu nad kvalitou obrazu, následující kroky vás provedou vším od nastavení prostředí až po uložení finálního JPEG. Pojďme začít!

## Rychlé odpovědi
- **Která knihovna zpracovává 2‑ a 7‑bitové JPEGy?** Aspose.PSD for Java.  
- **Minimální verze Javy?** JDK 8 nebo novější.  
- **Potřebuji licenci pro vývoj?** Bezplatná zkušební verze funguje pro hodnocení; pro produkci je vyžadována komerční licence.  
- **Mohu změnit barevný režim?** Ano – CMYK, YCCK a další režimy jsou podporovány pomocí `JpegCompressionColorMode`.  
- **Jaké snížení velikosti souboru mohu očekávat?** Použití 2‑bitů na kanál může zmenšit JPEG až o 80 % ve srovnání se 8‑bitovým výstupem.

## Co je java tutoriál zpracování obrazu?
Java tutoriál zpracování obrazu je krok‑za‑krokem průvodce, který učí vývojáře, jak programově manipulovat s obrazovými daty pomocí Javy. Pokrývá načítání různých formátů, aplikaci transformací, úpravu nastavení barev a komprese a ukládání výsledků, což vám umožní vytvořit vlastní workflow pro zpracování obrázků.

## Proč používat Aspose.PSD for Java?
Aspose.PSD for Java poskytuje komplexní API pro práci se soubory Photoshopu, aniž by bylo nutné mít samotný Photoshop. Podporuje více než 30 formátů obrázků, pracuje se soubory až do 2 GB pomocí streamování dat a nabízí jemnou kontrolu nad vrstvami, kanály a barevnými profily, což z něj činí ideální řešení pro vysoce výkonné server‑side zpracování.

## Import balíčků
Nejprve přidejte JAR Aspose.PSD do classpath vašeho projektu. Poté importujte požadované jmenné prostory:

```java
import com.aspose.psd.Image;
import com.aspose.psd.fileformats.jpeg.JpegCompressionColorMode;
import com.aspose.psd.fileformats.jpeg.JpegCompressionMode;
import com.aspose.psd.fileformats.psd.PsdImage;
import com.aspose.psd.imageoptions.JpegOptions;
```

## Jak načíst PSD obrázek v Javě?
Pro načtení souboru PSD zavolejte statickou metodu `load` třídy `Image` a výsledek přetypujte na `PsdImage`. Tím vytvoříte v‑paměti reprezentaci dokumentu Photoshop, která vám poskytne přístup k jeho vrstvám, kanálům, maskám a metadatům, jež můžete následně manipulovat nebo exportovat do jiných formátů.

`PsdImage` je hlavní třída Aspose.PSD, která představuje dokument Photoshop v paměti a umožňuje operace čtení/zápisu na jeho obsah.

```java
String dataDir = "Your Document Directory";
PsdImage image = (PsdImage) Image.load(dataDir + "PsdImage.psd");
```

## Jak nakonfigurovat JPEG možnosti pro 2‑ nebo 7‑bitový výstup?
Vytvořte novou instanci `JpegOptions` a nastavte její vlastnosti tak, aby odpovídaly požadovanému výstupu. Použijte `setColorType` k výběru vhodného `JpegCompressionColorMode` (např. CMYK nebo YCCK) a `setCompressionType` k výběru kompresního algoritmu. Nakonec přiřaďte hodnotu `bitsPerChannel` (2 nebo 7) pro řízení bitové hloubky každého barevného kanálu.

```java
JpegOptions options = new JpegOptions();
options.setColorType(JpegCompressionColorMode.Cmyk);
options.setCompressionType(JpegCompressionMode.JpegLs);
```

## Jak nastavit bity na kanál pro low‑bit JPEGy?
`bitsPerChannel` určuje počet bitů použitých pro každý barevný kanál ve výstupním JPEGu. Nastavením této vlastnosti na 2 se každý kanál sníží na dva bity, což vytváří silně komprimovaný obrázek s patrným páskováním, zatímco hodnota 7 zachovává více detailů a dává velikost souboru mezi extrémním low‑bit a standardním 8‑bitovým výstupem. Vyberte hodnotu, která vyvažuje kvalitu a velikost pro váš případ použití.

```java
byte bpp = 2;
options.setBitsPerChannel(bpp);
```

## Jak aplikovat barevné profily (volitelné)?
`ICCProfile` představuje profil International Color Consortium, který popisuje barevné charakteristiky zařízení nebo pracovního prostoru. Pokud máte vlastní ICC soubor, načtěte jej pomocí `ICCProfile.getInstance(path)` a přiřaďte jej k vlastnosti `iccProfile` objektu `jpegOptions`. Pokud tuto vlastnost necháte null, Aspose.PSD použije výchozí systémový profil, který funguje ve většině scénářů.

```java
options.setRgbColorProfile(null);
options.setCmykColorProfile(null);
```

## Jak uložit zpracovaný obrázek jako JPEG?
Metoda `save` zapíše obrázek do souboru pomocí poskytnutých možností. Zavolejte ji na instanci `PsdImage`, předáte cílový název souboru (včetně přípony .jpg) a nakonfigurované `JpegOptions`. Knihovna provede kódování, aplikaci vybraných bitů‑na‑kanál a barevného profilu a vytvoří JPEG, který odpovídá vašim specifikacím.

```java
image.save(dataDir + "2_7BitsJPEG_output.jpg", options);
```

## Časté problémy a řešení
- **Chyba – soubor je příliš velký** – Ujistěte se, že používáte nejnovější verzi Aspose.PSD, která streamuje data a zabraňuje načítání celého souboru do RAM.  
- **Neočekávané barvy** – Ověřte, že vybraný `JpegCompressionColorMode` odpovídá barevnému prostoru vašeho zdrojového obrázku.  
- **Chybějící ICC profil** – Pokud potřebujete konkrétní profil, načtěte jej pomocí `ICCProfile.getInstance(path)` a přiřaďte jej k `JpegOptions`.
