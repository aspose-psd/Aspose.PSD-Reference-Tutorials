# JPEG görüntü yönlendirmesini Java'da otomatik düzeltme

## Giriş
Bugünün dijital çağında, görüntüleri programlı olarak işlemek ve optimize etmek, çeşitli alanlardaki geliştiriciler için hayati bir görev haline gelmiştir. **Auto correct JPEG orientation**, farklı cihazlarda çekilen fotoğraflarla çalışırken yaygın bir gereksinimdir. Aspose.PSD for Java, PSD, JPEG ve diğer görüntü formatlarını verimli bir şekilde işlemek için güçlü araçlar sunar. Bu öğreticide, Aspose.PSD for Java kullanarak JPEG görüntü yönlendirmesini otomatik olarak düzeltmeye odaklanacağız. Fotoğraf düzenleme uygulaması geliştiriyor, bir CMS'de görüntü kaynaklarını yönetiyor ya da görüntü işleme hatlarını otomatikleştiriyor olun, bu yeteneği sorunsuz bir şekilde entegre etmeyi öğreneceksiniz.

## Hızlı cevaplar
- **Auto correct JPEG orientation** ne yapar? EXIF döndürme verilerini okur ve görüntüyü herhangi bir cihazda dik duracak şekilde döndürür.  
- **Hangi kütüphane döndürmeyi yönetir?** Aspose.PSD for Java, yerleşik EXIF işleme ve otomatik döndürme sağlar.

- **Hangi Java sürümleri destekleniyor?** Aspose.PSD, JDK 8 ile 21 arasında çalışır.

## Auto correct JPEG orientation nedir?
Auto correct JPEG orientation, bir görüntünün EXIF “Orientation” etiketinin otomatik olarak tespit edilmesi ve ardından bitmap'in dik duracak şekilde döndürülmesidir, böylece manuel müdahale gerekmez. Bu süreç, JPEG dosyasına gömülü meta verileri okur, gerekli döndürme veya çevirme işlemini belirler ve görsel temsili fotoğrafçının niyetine tüm izleme platformlarında uyması için uygular.

## Paketleri içe aktar
Örneğe başlamadan önce, Aspose.PSD for Java'dan gerekli paketleri içe aktardığınızdan emin olun. `Image` sınıfı, görüntüleri yüklemek ve kaydetmek için temel tiptir, `JpegExifData` EXIF meta verilerine erişim sağlar ve küçük resim kaynak sınıfları gömülü JPEG ön izlemelerini temsil eder.  

```java
import com.aspose.psd.Image;
import com.aspose.psd.exif.JpegExifData;
import com.aspose.psd.fileformats.psd.PsdImage;
import com.aspose.psd.fileformats.psd.resources.Thumbnail4Resource;
import com.aspose.psd.fileformats.psd.resources.ThumbnailResource;
```

## Aspose.PSD ile Java'da JPEG yönlendirmesini otomatik düzeltme nasıl yapılır?
Hedef PSD dosyasını yükleyin, gömülü JPEG küçük resmini bulun, Aspose.PSD'nin EXIF yönlendirmesini okumasını sağlayın, otomatik döndürmeyi uygulayın ve sonunda düzeltilmiş görüntüyü kaydedin. Bu iş akışı sadece birkaç metod çağrısı gerektirir ve bir PSD konteynerine gömülü herhangi bir JPEG görüntüsü için çalışır, tek görüntü ve toplu işleme senaryoları için uygundur.

## Adım 1: PSD görüntüsünü yükleyin
`PsdImage` sınıfı bir PSD dosyasını temsil eder ve gömülü JPEG küçük resimler dahil olmak üzere kaynaklarına erişim sağlar.  
İlk olarak, yönlendirmesi düzeltilmesi gereken JPEG küçük resmi içeren PSD görüntüsünü yükleyin:

```java
String dataDir = "Your Document Directory";
PsdImage image = (PsdImage)Image.load(dataDir + "1280px-Zebras_Serengeti.psd");
```
`"Your Document Directory"` ifadesini PSD dosyanızın bulunduğu gerçek dizin yolu ile değiştirin.

## Adım 2: Görüntü kaynakları üzerinde döngü
Sonra, JPEG küçük resim kaynağını bulmak için görüntü kaynakları üzerinde döngü yapın. `ThumbnailResource` ve `Thumbnail4Resource`, bir PSD dosyasındaki gömülü JPEG ön izlemelerinin farklı sürümlerini temsil eder.

```java
for (int i = 0; i < image.getImageResources().length; i++) {
    // Find thumbnail resource. Typically they are in the Jpeg file format.
    if (image.getImageResources()[i] instanceof ThumbnailResource || image.getImageResources()[i] instanceof Thumbnail4Resource) {
        // Adjust thumbnail data.
        ThumbnailResource thumbnail = (ThumbnailResource) image.getImageResources()[i];
        JpegExifData exifData = thumbnail.getJpegOptions().getExifData();
        if (exifData != null && exifData.getThumbnail() != null) {
            // If there is a thumbnail stored, auto-rotate it.
            PsdImage jpegImage = (PsdImage) exifData.getThumbnail();
            if (jpegImage != null) {
                jpegImage.autoRotate();
            }
        }
    }
}
```

## Adım 3: Görüntüyü kaydedin
Son olarak, otomatik döndürmeyi uyguladıktan sonra düzeltilmiş görüntüyü kaydedin:

```java
image.save();
```
Bu adım, görüntüde yapılan değişikliklerin kalıcı olmasını sağlar.

## Yaygın sorunlar ve hata ayıklama
- **EXIF etiketi algılanmadı** – JPEG küçük resminin gerçekten bir Orientation etiketi içerdiğinden emin olun; bazı kameralar bunu eklemez.  
- **Büyük dosyalarda bellek hataları** – Bellek kullanımını düşük tutmak için `PsdImage.load(..., LoadOptions)` ile `LoadOptions.setLoadAllResources(false)` kullanın.  
- **Yanlış döndürme yönü** – En son Aspose.PSD sürümünü kullandığınızdan emin olun; eski sürümlerde belirli yönlendirme değerleriyle ilgili bilinen bir hata vardı.
