## O que é uma miniatura EXIF?
Uma miniatura EXIF é uma imagem de baixa resolução armazenada dentro do bloco de metadados EXIF de um arquivo JPEG. Ela permite a geração rápida de pré‑visualizações em navegadores de arquivos e ferramentas de gerenciamento de ativos digitais. Normalmente com tamanho em torno de 160 × 120 pixels, a miniatura fornece uma pista visual sem carregar a imagem em resolução completa, reduzindo largura de banda e melhorando o desempenho.

## Como adicionar miniatura EXIF em Java?
PsdImage é a classe do Aspose.PSD para carregar um arquivo de imagem; use `new PsdImage("input.jpg")` para abrir o JPEG. Crie uma Thumbnail (uma pequena imagem de pré‑visualização) a partir de um Bitmap ou array de bytes, atribua-a a `ExifData.Thumbnail` e salve. A biblioteca atualiza automaticamente tags relacionadas, como `ExifTag.ThumbnailLength` e `ExifTag.ThumbnailOffset`.
