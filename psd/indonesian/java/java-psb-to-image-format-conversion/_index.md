## Cara mengonversi PSB ke JPG di Java?
**PsdImage** adalah kelas Aspose.PSD yang mewakili dokumen Photoshop dalam memori. **SaveFormat.Jpeg** adalah nilai enum yang memberi tahu perpustakaan untuk menulis gambar sebagai file JPEG. Muat file PSB Anda dengan `PsdImage` dan panggil `save` dengan menyebutkan `SaveFormat.Jpeg`. Pemanggilan satu baris ini menulis JPG berkualitas tinggi sambil mempertahankan resolusi dan kedalaman warna gambar asli. Anda juga dapat mengatur tingkat kompresi dan pengaturan DPI melalui objek `JpegOptions` untuk menyempurnakan kualitas output.

Mengonversi PSB ke JPG di Java lebih sederhana daripada yang Anda kira. Aspose.PSD menyediakan metode yang disederhanakan untuk mengubah file PSB Anda menjadi gambar JPG berkualitas tinggi.
