## Csomagok importálása
Az első lépés, hogy az Aspose.PSD osztályokat elérhetővé tedd a projektedben. Add hozzá a JAR-t manuálisan a classpath-hez, vagy a Maven függőséget a `pom.xml`‑ben.  
```java
import com.aspose.psd.Image;
import com.aspose.psd.fileformats.ai.AiImage;
import com.aspose.psd.imageoptions.PsdOptions;
```  
Alternatívaként letöltheted a JAR fájlt a [Aspose.PSD for Java download page](https://releases.aspose.com/psd/java/) oldalról, és manuálisan hozzáadhatod a projekthez.  
Tördeljük le a folyamatot egyszerű, kezelhető lépésekre.

## 1. lépés: A projekt beállítása
Először hozz létre egy új Java projektet az IDE-dben.

### Új projekt létrehozása
1. Nyisd meg az IDE-t, és hozz létre egy új Java projektet.  
2. Adj neki egy értelmes nevet, például **AItoPSDConverter**.  

### Aspose.PSD könyvtár hozzáadása
1. Ha letöltötted a JAR fájlt, add hozzá a projekt build útvonalához a *Project → Properties → Libraries* menüponton keresztül.  
2. Ha Maven-t használsz, add hozzá a következő függőséget a `pom.xml`‑hez (cseréld le a verziót a legújabbra):

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-psd</artifactId>
    <version>24.12</version>
</dependency>
```

## 2. lépés: AI fájl betöltése
Miután a könyvtár a classpath‑on van, betöltheted a forrás Illustrator fájlt.  
```java
String dataDir = "Your Document Directory"; 
String sourceFileName = dataDir + "34992OStroke.ai";       
AiImage image = (AiImage) Image.load(sourceFileName);
```  
A `PsdImage` osztály beolvassa az AI fájlt a memóriába, megőrizve a vektoradatokat a későbbi konverzióhoz.

## 3. lépés: PSD beállítások megadása
Mentés előtt érdemes szabályozni a színmódot, felbontást vagy a rétegkezelést.  
```java
PsdOptions options = new PsdOptions();
```  
Az Aspose.PSD biztosítja a `PsdOptions` objektumot, ahol ezeket a paramétereket adhatod meg.

## 4. lépés: AI fájl mentése PSD‑ként
Végül írd a konvertált képet lemezre PSD fájlként.  
```java
String outFileName = dataDir + "34992OStroke.psd";
image.save(outFileName, options);
```  
A `save` metódus kezeli a formátumspecifikus részleteket, egy Photoshop‑kompatibilis fájlt hozva létre, amely készen áll a további szerkesztésre.
