## Cos'è una miniatura EXIF?
Una miniatura EXIF è un'immagine piccola e a bassa risoluzione memorizzata all'interno del blocco di metadati EXIF di un file JPEG. Consente una rapida generazione di anteprime nei browser di file e negli strumenti di gestione delle risorse digitali. Tipicamente di dimensioni intorno a 160 × 120 pixel, la miniatura fornisce un'indicazione visiva senza caricare l'immagine a piena risoluzione, riducendo la larghezza di banda e migliorando le prestazioni.

## Come aggiungere una miniatura EXIF in Java?
PsdImage è la classe di Aspose.PSD per caricare un file immagine; usa `new PsdImage("input.jpg")` per aprire il JPEG. Crea una Thumbnail (una piccola immagine di anteprima) da un Bitmap o da un array di byte, assegnala a `ExifData.Thumbnail` e salva. La libreria aggiorna automaticamente i tag correlati come `ExifTag.ThumbnailLength` e `ExifTag.ThumbnailOffset`.
