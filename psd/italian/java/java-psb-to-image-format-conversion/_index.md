## Come convertire PSB in JPG in Java?
**PsdImage** è la classe di Aspose.PSD che rappresenta un documento Photoshop in memoria. **SaveFormat.Jpeg** è un valore enum che indica alla libreria di scrivere l'immagine come file JPEG. Carica il tuo file PSB con `PsdImage` e chiama `save` specificando `SaveFormat.Jpeg`. Questa chiamata a una riga scrive un JPG di alta qualità preservando la risoluzione e la profondità colore dell'immagine originale.
