## Εισαγωγή πακέτων
Η κλάση `PsdImage` είναι το κορυφαίο αντικείμενο του Aspose.PSD που αντιπροσωπεύει ένα μόνο έγγραφο Photoshop στη μνήμη, εκθέτοντας στρώματα και πόρους για επεξεργασία.  

```java
import com.aspose.psd.Image;
import com.aspose.psd.examples.Utils.Assert;
import com.aspose.psd.fileformats.psd.PsdImage;
import com.aspose.psd.fileformats.psd.layers.Layer;
import com.aspose.psd.fileformats.psd.layers.LayerResource;
import com.aspose.psd.fileformats.psd.layers.adjustmentlayers.InvertAdjustmentLayer;
import com.aspose.psd.fileformats.psd.layers.layerresources.NvrtResource;
```

## Γιατί να διαβάσετε τα στρώματα PSD;
Η ανάγνωση των στρωμάτων PSD σας δίνει εικόνα για τη δομή του εγγράφου, επιτρέποντάς σας να απομονώσετε μεμονωμένους πόρους, να καταλάβετε ποιες προσαρμογές έχουν εφαρμοστεί και να επαναχρησιμοποιήσετε στοιχεία σε άλλα έργα ή μορφές. Αυτή η διαφάνεια είναι απαραίτητη για αυτοματοποίηση, εξαγωγή πόρων και διατήρηση συνέπειας σχεδίου σε πολλαπλά αρχεία.

- Εξαγωγή μεμονωμένων πόρων (π.χ., εικονίδια, μάσκες) για επαναχρησιμοποίηση  
- Αναγνώριση στρωμάτων που περιέχουν στρώμα προσαρμογής αντιστροφής για κατανόηση των επεξεργασιών εικόνας  
- Αυτοματοποίηση μαζικής επεξεργασίας αρχείων σχεδίασης  

## Βήμα 1: καθορίστε τον φάκελο προέλευσης
Ορίστε το φάκελο που περιέχει τα PSD που θέλετε να επεξεργαστείτε.

```java
String sourceDir = "Your Source Directory";
String inPsdFilePath = sourceDir + "InvertAdjustmentLayer.psd";
```

Αντικαταστήστε το `"Your Source Directory"` με την πραγματική διαδρομή στο μηχάνημά σας.

## Βήμα 2: φορτώστε το αρχείο PSD
`Image.load()` φορτώνει ένα αρχείο σε μια παρουσία `PsdImage`, αναλύοντας τη δομή του PSD ώστε να μπορείτε να ελέγξετε στρώματα, πόρους και δεδομένα προσαρμογής.

```java
PsdImage psdImage = (PsdImage)Image.load(inPsdFilePath);
```

Η μέθοδος ανοίγει το αρχείο και το προετοιμάζει για επιθεώρηση.

## Βήμα 3: αρχικοποιήστε τη μεταβλητή πόρου Nvrt
Η κλάση `NvrtResource` αντιπροσωπεύει τα δεδομένα προσαρμογής αντιστροφής που αποθηκεύονται μέσα σε ένα αρχείο Photoshop.  

```java
NvrtResource nvrtResource = null;
```

## Βήμα 4: αναζητήστε το στρώμα προσαρμογής αντιστροφής
`InvertAdjustmentLayer` είναι ο συγκεκριμένος τύπος στρώματος που εφαρμόζει το εφέ χρώματος αρνητικού. Με την επανάληψη μέσω της συλλογής στρωμάτων μπορείτε να εντοπίσετε αυτό το στρώμα και στη συνέχεια να ανακτήσετε το σχετικό `NvrtResource`.

```java
try {
    for (Layer layer : psdImage.getLayers()) {
        if (layer instanceof InvertAdjustmentLayer) {
            for (LayerResource layerResource : layer.getResources()) {
                if (layerResource instanceof NvrtResource) {
                    // The NvrtResource is found
                    nvrtResource = (NvrtResource)layerResource;
                    break;
                }
            }
        }
    }
} finally {
    psdImage.dispose();
}
```

Το μπλοκ `finally` εγγυάται ότι η εικόνα PSD απελευθερώνεται, διατηρώντας τη χρήση μνήμης καθαρή.

## Βήμα 5: επαληθεύστε τον πόρο Nvrt
Επιβεβαιώστε ότι ο πόρος εντοπίστηκε επιτυχώς ελέγχοντας τη μεταβλητή που γεμίσατε στο προηγούμενο βήμα.

```java
Assert.isNotNull(nvrtResource);
```

Αν η επιβεβαίωση περάσει, έχετε διαβάσει επιτυχώς τα στρώματα PSD και εξάγει τον πόρο Nvrt.

## Συχνά προβλήματα & συμβουλές
- **Null checks:** Πάντα επαληθεύστε ότι τα `psdImage` και τα αντικείμενα στρωμάτων δεν είναι null πριν τα προσπελάσετε.  
- **Resource disposal:** Η παράλειψη του `psdImage.dispose()` μπορεί να προκαλέσει διαρροές μνήμης σε εφαρμογές που τρέχουν πολύ χρόνο.  
- **File path issues:** Χρησιμοποιήστε απόλυτες διαδρομές ή βεβαιωθείτε ότι ο τρέχων φάκελος είναι σωστά ορισμένος για να αποφύγετε `FileNotFoundException`.  
- **Batch processing note:** Κατά την επανάληψη πάνω σε πολλά αρχεία, επανεκκινήστε το `PsdImage` μέσα στο βρόχο και το απελευθερώστε αμέσως μετά την ολοκλήρωση επεξεργασίας κάθε αρχείου.
