## Εισαγωγή πακέτων

Ο χώρος ονομάτων `com.aspose.psd` περιέχει όλες τις κλάσεις που θα χρειαστείτε. Εισάγετε τις στην αρχή του αρχείου πηγαίου κώδικα:

`Image` είναι η βασική κλάση που αντιπροσωπεύει έναν raster καμβά για δημιουργία ή επεξεργασία αρχείων PSD.  
`CompressionMethod` απαριθμεί τους υποστηριζόμενους αλγόριθμους συμπίεσης για αρχεία PSD.  
`PsdOptions` περιέχει ρυθμίσεις όπως η συμπίεση και η διαδρομή προέλευσης.  
`FileCreateSource` καθορίζει τη διαδρομή του αρχείου εξόδου και αν είναι προσωρινό.

```java
import com.aspose.psd.Image;

import com.aspose.psd.fileformats.psd.CompressionMethod;
import com.aspose.psd.imageoptions.PsdOptions;
import com.aspose.psd.sources.FileCreateSource;

```

## Πώς ορίζω τη διαδρομή καταλόγου του εγγράφου;

Ο ορισμός του φακέλου όπου θα γραφτεί το νέο αρχείο PSD σας δίνει πλήρη έλεγχο στην οργάνωση των αρχείων και αποτρέπει τη βιβλιοθήκη από τη χρήση προεπιλεγμένων προσωρινών τοποθεσιών. Χρησιμοποιήστε μια απόλυτη διαδρομή για βεβαιότητα, ή μια σχετική διαδρομή που επιλύεται από τον τρέχοντα φάκελο του έργου σας. Βεβαιωθείτε ότι ο φάκελος υπάρχει ή δημιουργήστε τον προγραμματιστικά πριν προχωρήσετε.

```java
String dataDir = "Your Document Directory";
```

## Βήμα 1: Ορισμός διαδρομής καταλόγου εγγράφου

Ρυθμίστε τη διαδρομή για τον κατάλογο του εγγράφου όπου θα δημιουργηθεί η εικόνα.

```java
String dataDir = "Your Document Directory";
```

```java
String desName = dataDir + "CreatingAnImageBySettingPath_out.psd";
```

## Πώς ορίζω το όνομα του αρχείου εξόδου;

Συνδυάστε τη διαδρομή του καταλόγου με ένα περιγραφικό όνομα αρχείου για να σχηματίσετε την πλήρη διαδρομή εξόδου. Αυτό το βήμα εξασφαλίζει ότι το αντικείμενο `Image` γνωρίζει ακριβώς πού να γράψει το αρχείο, αποφεύγοντας ασαφείς τοποθεσίες. Συμπεριλάβετε την επέκταση `.psd` και σκεφτείτε τη χρήση χρονικών σφραγίδων ή μοναδικών αναγνωριστικών για λειτουργίες παρτίδας.

```java
PsdOptions psdOptions = new PsdOptions();
psdOptions.setCompressionMethod(CompressionMethod.RLE);
```

## Βήμα 2: Ορισμός ονόματος αρχείου εξόδου

Ορίστε το όνομα του αρχείου εξόδου, συμπεριλαμβανομένου του καταλόγου εγγράφου.

```java
String desName = dataDir + "CreatingAnImageBySettingPath_out.psd";
```

```java
psdOptions.setSource(new FileCreateSource(desName, false));
```

## Πώς μπορώ να ρυθμίσω τη συμπίεση για το αρχείο PSD;

Επιλέξτε μια μέθοδο συμπίεσης που ισορροπεί το μέγεθος του αρχείου και την ταχύτητα επεξεργασίας. Η RLE (Run‑Length Encoding) προσφέρει γρήγορη συμπίεση με μέτρια μείωση μεγέθους, ενώ η ZIP παρέχει υψηλότερη συμπίεση με κόστος επιπλέον χρόνου CPU. Ορίστε τη ζητούμενη μέθοδο στην παρουσία `PsdOptions` πριν δημιουργήσετε την εικόνα.

```java
Image image = Image.create(psdOptions, 500, 500);
```

## Βήμα 3: Διαμόρφωση PsdOptions

Δημιουργήστε μια παρουσία του PsdOptions και διαμορφώστε τις ιδιότητές του, όπως τη μέθοδο συμπίεσης.

```java
PsdOptions psdOptions = new PsdOptions();
psdOptions.setCompressionMethod(CompressionMethod.RLE);
```

```java
image.save();
```

## Πώς ορίζω την ιδιότητα Source για προσωρινά ή μόνιμα αρχεία;

Η ιδιότητα `Source` ενημερώνει το Aspose.PSD αν το αρχείο εξόδου είναι προσωρινός χώρος εργασίας ή τελικό προϊόν. Με το να περάσετε `false` για τη σημαία `isTemporary`, εξασφαλίζετε ότι το αρχείο γράφεται μόνιμα στην τοποθεσία που καθορίσατε, καθιστώντας το άμεσα διαθέσιμο για άλλες διεργασίες.

## Βήμα 4: Ορισμός ιδιότητας Source

Ορίστε την ιδιότητα source για την παρουσία PsdOptions, καθορίζοντας το αρχείο εξόδου και αν είναι προσωρινό.

```java
psdOptions.setSource(new FileCreateSource(desName, false));
```

## Πώς δημιουργώ την εικόνα PSD με συγκεκριμένες διαστάσεις;

`Image.create` δημιουργεί έναν νέο κενό καμβά χρησιμοποιώντας τις διαστάσεις που παρέχετε, εφαρμόζοντας τις επιλογές που διαμορφώθηκαν στο `PsdOptions`. Αυτή η μέθοδος επιστρέφει ένα αντικείμενο `Image` που μπορείτε να επεξεργαστείτε περαιτέρω, να προσθέσετε στρώματα ή να αποθηκεύσετε απευθείας στο δίσκο μόλις ο καμβάς είναι έτοιμος.

## Βήμα 5: Δημιουργία εικόνας

Δημιουργήστε μια παρουσία του Image και καλέστε τη μέθοδο Create περνώντας το αντικείμενο PsdOptions και τις διαστάσεις της εικόνας.

```java
Image image = Image.create(psdOptions, 500, 500);
```

## Πώς αποθηκεύω το παραγόμενο αρχείο PSD στο δίσκο;

Καλώντας τη μέθοδο `save` στην παρουσία `Image` γράφει τα δεδομένα της εικόνας στη διαδρομή που ορίστηκε προηγουμένως. Η μέθοδος σέβεται τις ρυθμίσεις συμπίεσης και διασφαλίζει ότι το αρχείο κλείνει σωστά, καθιστώντας το έτοιμο για άμεση χρήση ή διανομή.

## Βήμα 6: Αποθήκευση της εικόνας

Αποθηκεύστε την δημιουργημένη εικόνα.

```java
image.save();
```

## Κοινά προβλήματα και λύσεις

- **Σφάλμα μη εύρεσης διαδρομής:** Επαληθεύστε ότι ο φάκελος υπάρχει και ότι η εφαρμογή σας έχει δικαιώματα εγγραφής. Χρησιμοποιήστε `new File(path).mkdirs()` για να δημιουργήσετε τους ελλείποντες φακέλους.  
- **Εξαίρεση μη υποστηριζόμενης συμπίεσης:** Βεβαιωθείτε ότι χρησιμοποιείτε μια μέθοδο συμπίεσης που υποστηρίζεται από την έκδοση PSD-στόχο (π.χ., ZIP για PSD‑v3).  
- **Υπέρβαση μνήμης σε μεγάλες εικόνες:** Ορίστε `psdOptions.isMemoryOptimized = true` για να μεταδίδετε δεδομένα σε ροή αντί να φορτώνετε ολόκληρη την εικόνα στη μνήμη RAM.
