## Εισαγωγή Πακέτων

Οι παρακάτω εισαγωγές φέρνουν τις απαραίτητες κλάσεις Aspose.PSD για τη διαχείριση εικόνας.  
```java
import com.aspose.psd.Color;
import com.aspose.psd.Image;

import com.aspose.psd.fileformats.psd.PsdImage;
import com.aspose.psd.fileformats.psd.layers.BlendMode;
import com.aspose.psd.fileformats.psd.layers.layereffects.ColorOverlayEffect;
import com.aspose.psd.imageloadoptions.PsdLoadOptions;
```

## Βήμα 1: Φόρτωση της εικόνας PSD

`PsImage` είναι η κύρια κλάση που χρησιμοποιείται για τη φόρτωση ενός αρχείου PSD στη μνήμη για επεξεργασία.  
```java
String sourceFileName = "Your Document Directory/ThreeRegularLayers.psd";
String exportPath = "Your Document Directory/ThreeRegularLayersChanged.psd";

PsdLoadOptions loadOptions = new PsdLoadOptions();
loadOptions.setLoadEffectsResource(true);

PsdImage im = (PsdImage)Image.load(sourceFileName, loadOptions);
```

## Βήμα 2: Προσθήκη Εφέ Επικάλυψης Χρώματος

`ColorOverlayEffect` ορίζει μια επικάλυψη χρώματος που μπορεί να εφαρμοστεί στις επιλογές ανάμειξης μιας στρώσης.  
```java
ColorOverlayEffect effect = im.getLayers()[1].getBlendingOptions().addColorOverlay();
effect.setColor(Color.getGreen());
effect.setOpacity((byte)128);
effect.setBlendMode(BlendMode.Normal);
```

## Βήμα 3: Αποθήκευση της Τροποποιημένης Εικόνας

Η μέθοδος `save` γράφει το επεξεργασμένο PSD ή την εξαγόμενη εικόνα στη συγκεκριμένη διαδρομή αρχείου.  
```java
im.save(exportPath);
```

## Συχνά Προβλήματα και Λύσεις

| Πρόβλημα | Αιτία | Διόρθωση |
|----------|-------|----------|
| **Το εφέ δεν είναι ορατό** | `loadOptions.setLoadEffectsResource(true)` παραλείπεται | Βεβαιωθείτε ότι η σημαία έχει οριστεί πριν τη φόρτωση του PSD. |
| **Η αδιαφάνεια φαίνεται λανθασμένη** | Χρήση υπογεγραμμένου `byte` με τιμές >127 | Κάντε cast σε `(byte)128` όπως φαίνεται, ή χρησιμοποιήστε αμεσυνοδικό int και διαιρέστε δια 255. |
| **Δείκτης στρώσης εκτός ορίων** | Λάθος αριθμός στρώσης | Επαληθεύστε τη σειρά των στρώσεων με `im.getLayers().length` ή ελέγξτε το PSD στο Photoshop. |
