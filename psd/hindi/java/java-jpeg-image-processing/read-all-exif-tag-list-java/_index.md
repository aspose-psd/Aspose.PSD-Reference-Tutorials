# Read exif tags java – PSD फ़ाइलों से सभी EXIF मेटाडेटा निकालें

### परिचय
जावा विकास में, Photoshop Document (PSD) फ़ाइलों से EXIF टैग पढ़ना इमेज‑प्रोसेसिंग पाइपलाइन, डिजिटल एसेट मैनेजमेंट, और फॉरेंसिक विश्लेषण के लिए एक सामान्य आवश्यकता है। **Read exif tags java** का उपयोग करके Aspose.PSD for Java आपको कैमरा सेटिंग्स, निर्माण तिथियों और अन्य मेटाडेटा को Photoshop खोले बिना प्राप्त करने देता है। यह ट्यूटोरियल आपको प्रत्येक चरण के माध्यम से ले जाता है, प्रोजेक्ट सेटअप से लेकर इमेज रिसोर्सेज़ पर इटरेट करने तक, ताकि आप आज ही अपने एप्लिकेशन में EXIF एक्सट्रैक्शन को एकीकृत कर सकें।

## त्वरित उत्तर
- **कौन सा लाइब्रेरी PSD फ़ाइलों में EXIF को संभालता है?** Aspose.PSD for Java.
- **न्यूनतम Java संस्करण क्या है?** Java 8 या बाद का।
- **क्या मुझे Photoshop लाइसेंस की आवश्यकता है?** नहीं, API Photoshop से स्वतंत्र रूप से काम करता है।
- **क्या मैं सभी EXIF टैग एक साथ निकाल सकता हूँ?** हाँ, इमेज रिसोर्सेज़ कलेक्शन के माध्यम से इटरेट करें।
- **क्या उत्पादन के लिए लाइसेंस आवश्यक है?** हाँ, एक कमर्शियल लाइसेंस मूल्यांकन सीमाओं को हटा देता है।

## Read exif tags java क्या है?
*Read exif tags java* वह प्रक्रिया है जिसमें जावा कोड का उपयोग करके PSD फ़ाइल में एम्बेडेड प्रत्येक EXIF मेटाडेटा एंट्री को प्रोग्रामेटिकली प्राप्त किया जाता है। यह ऑपरेशन तब आवश्यक होता है जब आपको कैमरा‑उत्पत्ति डेटा को संरक्षित करना हो या इमेज कलेक्शन की बैच विश्लेषण करना हो।

## सभी EXIF टैग पढ़ने के मुख्य चरण क्या हैं?
PSD फ़ाइल लोड करें, EXIF रिसोर्स को ढूँढें, और प्रत्येक टैग पर इटरेट करके उसका नाम और मान एकत्र करें। निम्नलिखित सेक्शन प्रत्येक चरण को संक्षिप्त व्याख्याओं के साथ विभाजित करते हैं।

पहले, `PsdImage.load` का उपयोग करके फ़ाइल खोलें। फिर, इमेज रिसोर्सेज़ कलेक्शन प्राप्त करें और उसके प्रकार से EXIF रिसोर्स की पहचान करें। इसे `ExifData` ऑब्जेक्ट में कास्ट करें, और अंत में उसके टैग मैप पर लूप करें, प्रत्येक कुंजी और उसके संबंधित मान को निकालते हुए। यह व्यवस्थित दृष्टिकोण सुनिश्चित करता है कि कोई भी मेटाडेटा छूट न जाए।

## पैकेज इम्पोर्ट करें
`PsdImage`, `ImageResource`, और `ExifData` क्लासेस `com.aspose.psd` नेमस्पेस से संबंधित हैं। इन्हें अपने स्रोत फ़ाइल के शीर्ष पर किसी भी अन्य कोड से पहले इम्पोर्ट करें।

`PsdImage` क्लास Aspose.PSD का एंट्री पॉइंट है PSD फ़ाइलों को खोलने और संशोधित करने के लिए।  
`ImageResource` क्लास PSD फ़ाइल के अंदर संग्रहीत एक सामान्य रिसोर्स ब्लॉक को दर्शाता है।  
`ExifData` क्लास व्यक्तिगत EXIF एंट्रीज़ तक स्ट्रॉन्गली‑टाइप्ड एक्सेस प्रदान करता है।

```java
import com.aspose.psd.Image;
import com.aspose.psd.exif.JpegExifData;
import com.aspose.psd.fileformats.psd.PsdImage;
import com.aspose.psd.fileformats.psd.resources.Thumbnail4Resource;
import com.aspose.psd.fileformats.psd.resources.ThumbnailResource;
import java.util.Properties;
```

## चरण 1: PSD फ़ाइल लोड करें
पहले, अपने PSD फ़ाइल का पाथ कंस्ट्रक्टर में पास करके एक `PsdImage` इंस्टेंस बनाएं। यह कार्रवाई फ़ाइल हेडर को पार्स करती है और आगे की जांच के लिए आंतरिक रिसोर्स कलेक्शन तैयार करती है।

```java
String dataDir = "Your Document Directory";
PsdImage image = (PsdImage)Image.load(dataDir + "example.psd");
```

## चरण 2: इमेज रिसोर्सेज़ पर इटरेट करें
अगला, `getImageResources()` कलेक्शन के माध्यम से चलें, उस रिसोर्स को ढूँढें जिसका टाइप `ImageResourceType.ExifData` है, और इसे `ExifData` में कास्ट करें। एक बार जब आपके पास `ExifData` ऑब्जेक्ट हो, तो आप उसके `getTags()` मैप को एने्यूमरेट करके प्रत्येक EXIF कुंजी/मान जोड़ी पढ़ सकते हैं।

```java
for(int i = 0; i < image.getImageResources().length; i++) {
    if (image.getImageResources()[i] instanceof ThumbnailResource || image.getImageResources()[i] instanceof Thumbnail4Resource) {
        ThumbnailResource thumbnail = (ThumbnailResource)image.getImageResources()[i];
        JpegExifData exifData = thumbnail.getJpegOptions().getExifData();
        if (exifData != null) {
            // Process EXIF data properties
            for(int j = 0; j < exifData.getProperties().length; j++) {
                System.out.println(exifData.getProperties()[j].getId() + ": " + exifData.getProperties()[j].getValue());
            }
        }
    }
}
```

## सामान्य समस्याएँ और समाधान
- **Null `ExifData` ऑब्जेक्ट** – कुछ PSD फ़ाइलों में EXIF जानकारी नहीं होती। इटरेट करने से पहले हमेशा `null` की जाँच करें।
- **बड़ी फ़ाइलें OutOfMemoryError का कारण बनती हैं** – केवल आवश्यक रिसोर्सेज़ लोड करने के लिए `PsdImage.load(..., new LoadOptions { setLoadAllResources(false) })` का उपयोग करें।
- **असमर्थित EXIF टैग प्रकार** – API वर्तमान में मानक टैग्स को मैप करती है; प्रोपाइटरी टैग्स रॉ बाइट एरे के रूप में दिखाई देते हैं और उन्हें कस्टम डिकोडिंग की आवश्यकता हो सकती है।
