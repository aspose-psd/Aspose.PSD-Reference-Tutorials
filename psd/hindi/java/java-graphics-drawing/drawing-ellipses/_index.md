# जावा में Aspose.PSD लाइब्रेरी का उपयोग करके दीर्घवृत्त कैसे बनाएं

## परिचय
इस ट्यूटोरियल में आप जावा में Aspose.PSD लाइब्रेरी का उपयोग करके **दीर्घवृत्त कैसे बनाएं** सीखेंगे। Aspose.PSD for Java एक मजबूत API है जो आपको Adobe Photoshop की आवश्यकता के बिना PSD फ़ाइलें बनाना, संपादित करना और निर्यात करना संभव बनाता है। दीर्घवृत्त जैसी आकृतियों को ड्रॉ करना किसी भी जावा इमेज‑प्रोसेसिंग प्रोजेक्ट की मूल कौशल है, और यह गाइड आपको हर चरण से ले जाता है—प्रोजेक्ट सेटअप से लेकर अंतिम बिटमैप को सहेजने तक।

## त्वरित उत्तर
- **जावा में दीर्घवृत्त ड्रॉ करने के लिए कौन सी लाइब्रेरी सबसे बेहतर है?** Aspose.PSD for Java.
- **कोड की कितनी पंक्तियों की आवश्यकता है?** लगभग दस पंक्तियाँ प्लस कुछ सेटअप स्टेटमेंट्स।
- **क्या विकास के लिए लाइसेंस चाहिए?** परीक्षण के लिए एक फ्री ट्रायल काम करता है; उत्पादन के लिए एक व्यावसायिक लाइसेंस आवश्यक है।
- **क्या मैं BMP, PNG, या JPEG में आउटपुट कर सकता हूँ?** हाँ, Aspose.PSD BMP, PNG, JPEG, और PSD को सपोर्ट करता है।
- **क्या API Java 8 और उसके बाद के संस्करणों के साथ संगत है?** Java 8‑21 पर पूरी तरह सपोर्टेड।

## Aspose.PSD for Java क्या है?
Aspose.PSD for Java एक शुद्ध‑जावा लाइब्रेरी है जो प्रोग्रामेटिक रूप से Photoshop PSD फ़ाइलों का निर्माण, हेरफेर और रूपांतरण सक्षम करती है। यह 100 से अधिक इमेज फ़ॉर्मेट्स को सपोर्ट करती है और पूरी दस्तावेज़ को मेमोरी में लोड किए बिना 2 GB तक की फ़ाइलों को संभाल सकती है।

## दीर्घवृत्त ड्रॉ करने के लिए Aspose.PSD का उपयोग क्यों करें?
Aspose.PSD उच्च प्रदर्शन प्रदान करता है, कई‑पृष्ठ दस्तावेज़ों को सेकंडों में प्रोसेस करता है, जबकि BMP, PNG, JPEG और PSD जैसे 100 से अधिक इनपुट और आउटपुट फ़ॉर्मेट्स को सपोर्ट करता है। यह पूरी तरह जावा में चलता है, जिससे नेटिव Photoshop की आवश्यकता समाप्त हो जाती है और यह CI/CD पाइपलाइन और क्लाउड‑आधारित सेवाओं के लिए आदर्श बन जाता है।

- बुनियादी जावा प्रोग्रामिंग ज्ञान।
- JDK 8 या उससे नया स्थापित हो।
- IntelliJ IDEA या Eclipse जैसे IDE।
- Aspose.PSD for Java लाइब्रेरी। आप इसे [Aspose.PSD for Java download page](https://releases.aspose.com/psd/java/) से डाउनलोड कर सकते हैं।

## पैकेज आयात करें
सबसे पहले, Aspose.PSD नेमस्पेस से उन क्लासेज़ को इम्पोर्ट करें जिनकी आपको आवश्यकता होगी।

## जावा में दीर्घवृत्त कैसे बनाएं?
Aspose.PSD लाइब्रेरी लोड करें, एक खाली PsdImage कैनवास बनाएं, एक Graphics ऑब्जेक्ट प्राप्त करें, वैकल्पिक रूप से बैकग्राउंड को साफ़ करें, फिर Pen ऑब्जेक्ट्स को इच्छित रंग और शैली के साथ उपयोग करके Rectangle सीमाओं के भीतर दीर्घवृत्त ड्रॉ करें। अंत में, छवि को BMP, PNG, या JPEG फ़ॉर्मेट में सहेजें। यह प्रक्रिया आमतौर पर 15 पंक्तियों से कम कोड की आवश्यकता रखती है।

## चरण 1: अपना जावा प्रोजेक्ट सेट अप करें
कोडिंग शुरू करने से पहले, सुनिश्चित करें कि आपका प्रोजेक्ट Aspose.PSD JAR को Maven/Gradle डिपेंडेंसी के रूप में शामिल करता है या JAR को क्लासपाथ में जोड़ता है।

## चरण 2: PsdImage का एक इंस्टेंस बनाएं
```java
import com.aspose.psd.Color;
import com.aspose.psd.Graphics;
import com.aspose.psd.Image;
import com.aspose.psd.Pen;
import com.aspose.psd.Rectangle;
import com.aspose.psd.brushes.SolidBrush;
import com.aspose.psd.fileformats.psd.PsdImage;
import com.aspose.psd.imageoptions.BmpOptions;
```

## चरण 3: ग्राफ़िक्स ऑब्जेक्ट को इनिशियलाइज़ करें
```java
Image image = new PsdImage(100, 100);
```

## चरण 4: ग्राफ़िक्स सतह को साफ़ करें
```java
Graphics graphics = new Graphics(image);
```

## चरण 5: डॉटेड दीर्घवृत्त बनाएं
```java
graphics.clear(Color.getYellow());
```

## चरण 6: निरंतर दीर्घवृत्त बनाएं
```java
graphics.drawEllipse(new Pen(Color.getRed()), new Rectangle(30, 10, 40, 80));
```

## चरण 7: छवि सहेजें
```java
graphics.drawEllipse(new Pen(new SolidBrush(Color.getBlue())), new Rectangle(10, 30, 80, 40));
```

```java
String outputPath = "Your Document Directory/Ellipse.bmp";
BmpOptions saveOptions = new BmpOptions();
saveOptions.setBitsPerPixel(32);
image.save(outputPath, saveOptions);
```

## सामान्य समस्याएँ और समाधान
- **छवि खाली दिख रही है:** ड्रॉ करने से पहले सुनिश्चित करें कि आपने `graphics.clear()` को एक दृश्यमान रंग के साथ कॉल किया है।
- **दीर्घवृत्त विकृत दिख रहा है:** पुष्टि करें कि `Rectangle` के आयाम छवि के अनुपात से मेल खाते हैं।
- **बड़ी फ़ाइलों पर मेमोरी समाप्ति त्रुटियाँ:** पूरे दस्तावेज़ को लोड करने के बजाय फ़ाइल के हिस्सों को प्रोसेस करने के लिए `PsdImage` की स्ट्रीमिंग API का उपयोग करें।
