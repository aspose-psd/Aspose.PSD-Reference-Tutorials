## पैकेज इम्पोर्ट करें

`com.aspose.psd` नेमस्पेस में सभी क्लासेज़ हैं जिनकी आपको आवश्यकता होगी। इन्हें अपने सोर्स फ़ाइल के शीर्ष पर इम्पोर्ट करें:

`Image` वह कोर क्लास है जो PSD फ़ाइलें बनाने या एडिट करने के लिए रास्टर कैनवास को दर्शाता है।  
`CompressionMethod` PSD फ़ाइलों के लिए समर्थित कंप्रेशन एल्गोरिदम को एनेमरेट करता है।  
`PsdOptions` कंप्रेशन और स्रोत पाथ जैसी कॉन्फ़िगरेशन रखता है।  
`FileCreateSource` आउटपुट फ़ाइल पाथ और यह टेम्पररी है या नहीं, को निर्दिष्ट करता है।

```java
import com.aspose.psd.Image;

import com.aspose.psd.fileformats.psd.CompressionMethod;
import com.aspose.psd.imageoptions.PsdOptions;
import com.aspose.psd.sources.FileCreateSource;

```

## डॉक्यूमेंट डायरेक्टरी पाथ कैसे सेट करें?

नया PSD फ़ाइल लिखे जाने वाले फ़ोल्डर को सेट करने से आपको फ़ाइल संगठन पर पूर्ण नियंत्रण मिलता है और लाइब्रेरी को डिफ़ॉल्ट टेम्पररी लोकेशन उपयोग करने से रोका जाता है। निश्चितता के लिए एक एब्सोल्यूट पाथ उपयोग करें, या एक रिलेटिव पाथ जो आपके प्रोजेक्ट की वर्किंग डायरेक्टरी से रिज़ॉल्व हो। आगे बढ़ने से पहले सुनिश्चित करें कि डायरेक्टरी मौजूद है या प्रोग्रामेटिकली इसे बनाएं।

```java
String dataDir = "Your Document Directory";
```

## स्टेप 1: डॉक्यूमेंट डायरेक्टरी पाथ सेट करें

इमेज बनायी जाने वाली आपकी डॉक्यूमेंट डायरेक्टरी के पाथ को सेट करें।

```java
String dataDir = "Your Document Directory";
```

```java
String desName = dataDir + "CreatingAnImageBySettingPath_out.psd";
```

## आउटपुट फ़ाइल नाम कैसे परिभाषित करें?

डायरेक्टरी पाथ को एक वर्णनात्मक फ़ाइल नाम के साथ मिलाकर पूर्ण आउटपुट पाथ बनाएं। यह स्टेप सुनिश्चित करता है कि `Image` ऑब्जेक्ट को ठीक पता हो कि फ़ाइल कहाँ लिखनी है, जिससे अस्पष्ट लोकेशन से बचा जा सके। `.psd` एक्सटेंशन शामिल करें और बैच ऑपरेशन्स के लिए टाइमस्टैम्प या यूनिक आइडेंटिफ़ायर उपयोग करने पर विचार करें।

```java
PsdOptions psdOptions = new PsdOptions();
psdOptions.setCompressionMethod(CompressionMethod.RLE);
```

## स्टेप 2: आउटपुट फ़ाइल नाम परिभाषित करें

आउटपुट फ़ाइल नाम को परिभाषित करें, जिसमें डॉक्यूमेंट डायरेक्टरी भी शामिल हो।

```java
String desName = dataDir + "CreatingAnImageBySettingPath_out.psd";
```

```java
psdOptions.setSource(new FileCreateSource(desName, false));
```

## PSD फ़ाइल के लिए कंप्रेशन कैसे कॉन्फ़िगर करें?

ऐसा कंप्रेशन मेथड चुनें जो फ़ाइल साइज और प्रोसेसिंग स्पीड के बीच संतुलन रखता हो। RLE (Run‑Length Encoding) तेज़ कंप्रेशन देता है साथ में मामूली साइज घटाव, जबकि ZIP अधिक कंप्रेशन देता है लेकिन अतिरिक्त CPU टाइम की लागत पर। इमेज बनाने से पहले `PsdOptions` इंस्टेंस पर इच्छित मेथड सेट करें।

```java
Image image = Image.create(psdOptions, 500, 500);
```

## स्टेप 3: PsdOptions कॉन्फ़िगर करें

PsdOptions का एक इंस्टेंस बनाएं और उसकी प्रॉपर्टीज़, जैसे कंप्रेशन मेथड, को कॉन्फ़िगर करें।

```java
PsdOptions psdOptions = new PsdOptions();
psdOptions.setCompressionMethod(CompressionMethod.RLE);
```

```java
image.save();
```

## टेम्पररी या परमानेंट फ़ाइलों के लिए सोर्स प्रॉपर्टी कैसे सेट करें?

`Source` प्रॉपर्टी Aspose.PSD को बताती है कि आउटपुट फ़ाइल टेम्पररी वर्कस्पेस है या अंतिम प्रोडक्ट। `isTemporary` फ़्लैग के लिए `false` पास करके, आप सुनिश्चित करते हैं कि फ़ाइल आपके द्वारा निर्दिष्ट लोकेशन पर स्थायी रूप से लिखी जाए, जिससे वह तुरंत अन्य प्रोसेसेस के लिए उपलब्ध हो जाए।

## सामान्य समस्याएँ और समाधान

- **Path not found error:** सुनिश्चित करें कि डायरेक्टरी मौजूद है और आपके एप्लिकेशन के पास लिखने की अनुमति है। गायब फ़ोल्डर्स बनाने के लिए `new File(path).mkdirs()` उपयोग करें।  
- **Unsupported compression exception:** सुनिश्चित करें कि आप लक्ष्य PSD संस्करण द्वारा समर्थित कंप्रेशन मेथड का उपयोग कर रहे हैं (उदाहरण के लिए, PSD‑v3 के लिए ZIP)।  
- **Memory overflow on large images:** `psdOptions.isMemoryOptimized = true` सेट करें ताकि डेटा को स्ट्रीम किया जा सके बजाय पूरी इमेज को RAM में लोड करने के।
