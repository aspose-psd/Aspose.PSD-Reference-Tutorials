# Export PSD als PNG mit 16‑Bit Graustufen-Farbmodus in Java

## Einführung
Das Exportieren von PSD als PNG bei Beibehaltung eines 16‑Bit Graustufen-Farbmodus gibt Ihnen die Tiefe eines professionellen Fotos und die universelle Kompatibilität von PNG. In diesem Leitfaden lernen Sie, wie Sie **den PSD-Farbmodus auf 16‑Bit Graustufen setzen** und dann **die PSD als PNG exportieren** mit Aspose.PSD für Java. Das Tutorial deckt alles von den Voraussetzungen bis zur Fehlersuche ab, sodass Sie den Workflow in jede Java‑basierte Bildpipeline integrieren können.

## Schnelle Antworten
- **Was beinhaltet „Export PSD als PNG“?** Laden Sie ein PSD, ändern optional den Farbmodus und speichern es als PNG‑Datei.  
- **Welche Aspose‑Klasse übernimmt die Konvertierung?** `PsdImage` lädt das PSD und `PngOptions` definiert die PNG‑Ausgabe‑Einstellungen.  
- **Benötige ich eine Lizenz für die Produktion?** Ja – eine Testversion funktioniert für Tests, aber für den kommerziellen Einsatz ist eine kostenpflichtige Lizenz erforderlich.  
- **Kann die 16‑Bit‑Tiefe im PNG beibehalten werden?** Absolut, indem Sie `PngColorType.GrayscaleWithAlpha` verwenden.  
- **Welche IDEs werden unterstützt?** Jede Java‑IDE – IntelliJ IDEA, Eclipse, VS Code oder NetBeans.

## Was ist Export PSD als PNG?
Export PSD als PNG ist der Vorgang, ein Adobe‑Photoshop‑Dokument (PSD) in eine Portable Network Graphics (PNG)‑Datei zu konvertieren, wobei die Pixeldaten und die Farbtiefe des Bildes erhalten bleiben. Diese Konvertierung wird häufig verwendet, um hochwertige Graustufen‑Assets im Web zu teilen, ohne tonale Details zu verlieren.

## Warum PSD als PNG mit 16‑Bit Graustufen exportieren?
Das Exportieren nach PNG bei Beibehaltung von 16‑Bit Graustufen bewahrt 65 536 Graustufen, was viel mehr tonale Fülle bietet als 8‑Bit‑Bilder. Die universelle Unterstützung von PNG stellt sicher, dass die Dateien in Browsern, mobilen Apps und Desktop‑Editoren ohne Qualitätsverlust angezeigt werden können, während die verlustfreie Kompression von Aspose.PSD garantiert, dass keine Artefakte entstehen.

## Wie man PSD als PNG Schritt für Schritt exportiert

## Wie setzen Sie den PSD-Farbmodus auf 16‑Bit Graustufen?
PsdImage ist die Aspose.PSD‑Klasse, die eine PSD‑Datei in den Speicher lädt und darstellt.  
ColorMode ist eine Aufzählung, die den Farbmodus eines PSD‑Bildes definiert.

Laden Sie das PSD mit `PsdImage`, ändern Sie dessen Farbmodus über die `ColorMode`‑Eigenschaft und speichern Sie dann die modifizierte Datei. Dieser Vorgang läuft vollständig im Speicher, wodurch Zwischen‑Dateien entfallen und die Konvertierung schnell und effizient ist.

```java
import com.aspose.psd.*;
import com.aspose.psd.fileformats.png.PngColorType;
import com.aspose.psd.fileformats.psd.ColorModes;
import com.aspose.psd.fileformats.psd.CompressionMethod;
import com.aspose.psd.fileformats.psd.PsdImage;
import com.aspose.psd.imageoptions.PngOptions;
import com.aspose.psd.imageoptions.PsdOptions;
import com.aspose.psd.system.Enum;
```

Diese Importe geben Ihnen Zugriff auf die Funktionen, die Sie zum Manipulieren von PSD‑Dateien, zum Setzen des Farbmodus und zum Exportieren des Ergebnisses als PNG verwenden.

## Wie laden Sie das PSD und wenden den 16‑Bit Graustufen‑Modus an?
PsdImage ist die Aspose.PSD‑Klasse, die eine PSD‑Datei in den Speicher lädt.  
ColorMode.GRAYSCALE_16 ist ein Aufzählungswert, der das Bild auf 16‑Bit Graustufen setzt.  
`channelBitsCount` ist eine Eigenschaft, die die Anzahl der Bits pro Kanal angibt.

Innerhalb der Konvertierungsmethode bauen Sie die vollständigen Dateipfade zusammen, instanziieren `PsdImage` und ändern dessen `ColorMode` zu `ColorMode.GRAYSCALE_16`. Die Eigenschaft `channelBitsCount` muss auf 16 gesetzt werden, um die hohe Bit‑Tiefe beizubehalten, sodass das Bild alle tonalen Informationen behält.

```java
String filePath = sourceDir + file + ".psd";
String postfix = Enum.getName(ColorModes.class, colorMode) + channelBitsCount + "_" +
                 channelsCount + "_" + Enum.getName(CompressionMethod.class, compression);
String exportPath = outputDir + file + postfix + ".psd";
String pngExportPath = outputDir + file + postfix + ".png";
// Load a predefined 16-bit grayscale PSD
PsdImage image = (PsdImage)Image.load(filePath);
```

Der `postfix` hilft Ihnen, die für jede exportierte Datei verwendeten Einstellungen nachzuverfolgen.

## Wie zeichnen Sie einen dezenten Rand um das Bild (optional)?
`Graphics` ist eine Klasse, die Zeichenfähigkeiten auf einer `PsdImage`‑Leinwand bereitstellt.

Sie können optional ein graues Rechteck um das Bild zeichnen, um die Ausgabe während des Tests besser sichtbar zu machen. Dieser Schritt zeigt, wie man mit Ebenen und Grafikobjekten arbeitet, und das Rechteck wird dynamisch berechnet, sodass es unabhängig von der Bildgröße zentriert bleibt.

```java
try {
    RasterCachedImage raster = layerNumber >= 0 ? image.getLayers()[layerNumber] : image;
    // Draw a gray inner border around the perimeter of the layer
    Graphics graphics = new Graphics(raster);
    int width = raster.getWidth();
    int height = raster.getHeight();
    Rectangle rect = new Rectangle(
        width / 3,
        height / 3,
        width - (2 * (width / 3)) - 1,
        height - (2 * (height / 3)) - 1);
    graphics.drawRectangle(new Pen(Color.getDarkGray(), 1), rect);
```

Das Rechteck wird dynamisch berechnet, sodass es unabhängig von der Bildgröße zentriert bleibt.

## Wie speichern Sie das modifizierte PSD mit dem neuen Farbmodus?
`PsdOptions` ist eine Klasse, die steuert, wie eine PSD‑Datei gespeichert wird, einschließlich Farbmodus- und Bit‑Tiefeneinstellungen.

Nach dem Zeichnen (oder dem Überspringen dieses Schritts) rufen Sie `save` auf der `PsdImage`‑Instanz auf und übergeben ein `PsdOptions`‑Objekt, das die 16‑Bit Graustufen‑Konfiguration beibehält. Dadurch wird sichergestellt, dass das gespeicherte PSD den gewünschten Farbmodus ohne Datenverlust behält.

```java
    // Save a copy of PSD with specific characteristics
    PsdOptions psdOptions = new PsdOptions();
    psdOptions.setColorMode(colorMode);
    psdOptions.setChannelBitsCount(channelBitsCount);
    psdOptions.setChannelsCount(channelsCount);
    psdOptions.setCompressionMethod(compression);
    image.save(exportPath, psdOptions);
}
```

## Wie konvertieren Sie das PSD zu PNG bei Beibehaltung der 16‑Bit‑Tiefe?
`PngOptions` ist eine Klasse, die PNG‑Ausgabe‑Einstellungen wie Farbtyp und Kompressionsgrad definiert.  
`PngColorType.GrayscaleWithAlpha` ist ein Aufzählungswert, der 16‑Bit Graustufen‑Daten mit einem Alphakanal speichert.

Laden Sie das neu gespeicherte PSD, konfigurieren Sie `PngOptions` mit `PngColorType.GrayscaleWithAlpha` und rufen Sie `save` auf. Dadurch werden die 16‑Bit Graustufen‑Daten in der PNG‑Datei beibehalten, was ein verlustfreies, hochqualitatives Bild für weitere Verarbeitung oder Verteilung liefert.

```java
finally {
    image.dispose();
}
// Load the saved PSD
PsdImage image1 = (PsdImage)Image.load(exportPath);
try {
    // Convert the saved PSD to a grayscale PNG image
    PngOptions pngOptions = new PngOptions();
    pngOptions.setColorType(PngColorType.GrayscaleWithAlpha);
    image1.save(pngExportPath, pngOptions); // here should be no exception
}
finally {
    image1.dispose();
}
```

Jetzt haben Sie erfolgreich **PSD als PNG exportiert** und dabei die hochwertige 16‑Bit Graustufen‑Daten beibehalten.

## Häufige Probleme und Lösungen
| Problem | Warum es passiert | Lösung |
|---------|-------------------|--------|
| **„Unsupported color type“-Ausnahme** | Versuch, ein PSD mit einer nicht unterstützten Kanalkonfiguration zu speichern. | Stellen Sie sicher, dass `channelBitsCount` der tatsächlichen Bit‑Tiefe (16) entspricht und `channelsCount` für Graustufen (1) korrekt ist. |
| **Datei nicht gefunden** | Falscher Quellverzeichnis‑Pfad. | Überprüfen Sie den `sourceDir`‑String und vergewissern Sie sich, dass die PSD‑Datei an diesem Ort existiert. |
| **Ausgabe‑PNG erscheint schwarz** | PNG wurde ohne korrekte Alpha‑Verarbeitung gespeichert. | Verwenden Sie `PngColorType.GrayscaleWithAlpha` wie oben gezeigt. |
| **Speicherüberlauf bei großen PSDs** | Laden der gesamten Datei in den Speicher. | Aktivieren Sie den Streaming‑Modus über `PsdImage.load(inputStream, new LoadOptions())`, um große Dateien effizient zu verarbeiten. |
