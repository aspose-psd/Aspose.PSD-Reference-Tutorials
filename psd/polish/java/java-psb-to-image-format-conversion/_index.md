## Jak przekonwertować PSB do JPG w Javie?
**PsdImage** jest klasą Aspose.PSD reprezentującą dokument Photoshop w pamięci. **SaveFormat.Jpeg** jest wartością wyliczeniową, która instruuje bibliotekę, aby zapisała obraz jako plik JPEG. Załaduj swój plik PSB przy użyciu `PsdImage` i wywołaj `save`, podając `SaveFormat.Jpeg`. To jednowierszowe wywołanie zapisuje wysokiej jakości JPG, zachowując rozdzielczość i głębię kolorów oryginalnego obrazu.
