# Samouczek przetwarzania obrazów w Javie: obsługa JPEG‑ów 2‑ i 7‑bitowych

## Wprowadzenie
W tym **java image processing tutorial** odkryjesz, jak używać biblioteki Aspose.PSD for Java do wczytania pliku PSD i wyeksportowania go jako JPEG‑a 2‑ lub 7‑bitowego. Niezależnie od tego, czy tworzysz usługę konwersji wsadowej, czy potrzebujesz precyzyjnej kontroli nad jakością obrazu, poniższe kroki przeprowadzą Cię przez wszystko, od konfiguracji środowiska po zapisanie finalnego JPEG‑a. Zaczynajmy!

## Szybkie odpowiedzi
- **Która biblioteka obsługuje JPEG‑y 2‑ i 7‑bitowe?** Aspose.PSD for Java.  
- **Minimalna wersja Java?** JDK 8 lub nowsza.  
- **Czy potrzebuję licencji do rozwoju?** Darmowa wersja próbna wystarcza do oceny; licencja komercyjna jest wymagana w produkcji.  
- **Czy mogę zmienić tryb kolorów?** Tak – CMYK, YCCK i inne tryby są obsługiwane przez `JpegCompressionColorMode`.  
- **Jakie zmniejszenie rozmiaru pliku mogę oczekiwać?** Użycie 2‑bitów na kanał może zmniejszyć JPEG o nawet 80 % w porównaniu do wyjścia 8‑bitowego.

## Czym jest java image processing tutorial?
Samouczek przetwarzania obrazów w Javie to przewodnik krok po kroku, który uczy programistów, jak programowo manipulować danymi obrazu przy użyciu Javy. ## Dlaczego warto używać Aspose.PSD for Java?

Obsługuje ponad 30 formatów obrazów, radzi sobie z plikami do 2 GB dzięki strumieniowaniu danych i oferuje precyzyjną kontrolę nad warstwami, kanałami i profilami kolorów, co czyni go idealnym do wysokowydajnego przetwarzania po stronie serwera.

## Importowanie pakietów
Najpierw dodaj plik JAR Aspose.PSD do classpathu swojego projektu. Następnie zaimportuj wymagane przestrzenie nazw:

```java
import com.aspose.psd.Image;
import com.aspose.psd.fileformats.jpeg.JpegCompressionColorMode;
import com.aspose.psd.fileformats.jpeg.JpegCompressionMode;
import com.aspose.psd.fileformats.psd.PsdImage;
import com.aspose.psd.imageoptions.JpegOptions;
```

## Jak wczytać obraz PSD w Javie?
Aby wczytać plik PSD, wywołaj statyczną metodę `load` klasy `Image` i rzutuj wynik na `PsdImage`. Tworzy to reprezentację dokumentu Photoshop w pamięci, dając dostęp do jego warstw, kanałów, masek i metadanych, które możesz następnie manipulować lub eksportować do innych formatów.

`PsdImage` jest podstawową klasą Aspose.PSD, która reprezentuje dokument Photoshop w pamięci, umożliwiając operacje odczytu/zapisu na jego zawartości.

```java
String dataDir = "Your Document Directory";
PsdImage image = (PsdImage) Image.load(dataDir + "PsdImage.psd");
```

## Jak skonfigurować opcje JPEG dla wyjścia 2‑ lub 7‑bitowego?
Utwórz nową instancję `JpegOptions` i ustaw jej właściwości tak, aby odpowiadały pożądanemu wyjściu. Użyj `setColorType`, aby wybrać odpowiedni `JpegCompressionColorMode` (np. CMYK lub YCCK), oraz `setCompressionType`, aby wybrać algorytm kompresji. Na koniec przypisz wartość `bitsPerChannel` (2 lub 7), aby kontrolować głębokość bitową każdego kanału kolorów.

```java
JpegOptions options = new JpegOptions();
options.setColorType(JpegCompressionColorMode.Cmyk);
options.setCompressionType(JpegCompressionMode.JpegLs);
```

## Jak ustawić liczbę bitów na kanał dla JPEG‑ów o niskiej liczbie bitów?
`bitsPerChannel` określa liczbę bitów używanych dla każdego kanału kolorów w wyjściowym JPEG‑ie. Ustawienie tej właściwości na 2 zmniejsza każdy kanał do dwóch bitów, co daje mocno skompresowany obraz z widocznymi pasmami, natomiast wartość 7 zachowuje więcej szczegółów i daje rozmiar pliku pomiędzy skrajnym niskobitowym a standardowym 8‑bitowym wyjściem. Wybierz wartość, która zapewnia odpowiedni kompromis między jakością a rozmiarem dla Twojego przypadku.

```java
byte bpp = 2;
options.setBitsPerChannel(bpp);
```

## Jak zastosować profile kolorów (opcjonalnie)?
`ICCProfile` reprezentuje profil International Color Consortium opisujący charakterystykę kolorów urządzenia lub przestrzeni roboczej. Jeśli masz własny plik ICC, wczytaj go za pomocą `ICCProfile.getInstance(path)` i przypisz do właściwości `iccProfile` obiektu `jpegOptions`. Pozostawienie tej właściwości jako null powoduje, że Aspose.PSD użyje domyślnego profilu systemowego, co działa w większości scenariuszy.

```java
options.setRgbColorProfile(null);
options.setCmykColorProfile(null);
```

## Jak zapisać przetworzony obraz jako JPEG?
Metoda `save` zapisuje obraz do pliku przy użyciu podanych opcji. Wywołaj ją na instancji `PsdImage`, przekazując docelową nazwę pliku (z rozszerzeniem .jpg) oraz skonfigurowane `JpegOptions`. Biblioteka obsługuje kodowanie, zastosowanie wybranej liczby bitów na kanał oraz profilu kolorów i generuje JPEG spełniający Twoje wymagania.

```java
image.save(dataDir + "2_7BitsJPEG_output.jpg", options);
```

## Typowe problemy i rozwiązania
- **Błąd: plik za duży** – Upewnij się, że używasz najnowszej wersji Aspose.PSD, która strumieniuje dane i unika ładowania całego pliku do pamięci RAM.  
- **Nieoczekiwane kolory** – Zweryfikuj, czy wybrany `JpegCompressionColorMode` odpowiada przestrzeni kolorów Twojego obrazu źródłowego.  
- **Brak profilu ICC** – Jeśli potrzebujesz konkretnego profilu, wczytaj go za pomocą `ICCProfile.getInstance(path)` i przypisz do `JpegOptions`.
