## Что такое миниатюра EXIF?
Миниатюра EXIF — это небольшое, низкокачественное изображение, хранящееся внутри блока метаданных EXIF JPEG‑файла. Она позволяет быстро генерировать превью в файловых менеджерах и системах управления цифровыми активами. Обычно размер составляет около 160 × 120 пикселей; миниатюра даёт визуальный сигнал без загрузки изображения в полном разрешении, снижая трафик и повышая производительность.

## Как добавить миниатюру EXIF в Java?
`PsdImage` — класс Aspose.PSD для загрузки файлов изображений; используйте `new PsdImage("input.jpg")`, чтобы открыть JPEG. Создайте Thumbnail (небольшое превью) из Bitmap или массива байтов, присвойте его `ExifData.Thumbnail` и сохраните. Библиотека автоматически обновляет связанные теги, такие как `ExifTag.ThumbnailLength` и `ExifTag.ThumbnailOffset`.
