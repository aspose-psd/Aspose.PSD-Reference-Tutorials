## Как конвертировать PSB в JPG в Java?
**PsdImage** — это класс Aspose.PSD, представляющий документ Photoshop в памяти. **SaveFormat.Jpeg** — значение перечисления, указывающее библиотеке записать изображение как файл JPEG. Загрузите ваш файл PSB с помощью `PsdImage` и вызовите `save`, указав `SaveFormat.Jpeg`. Этот однострочный вызов записывает JPG высокого качества, сохраняя оригинальное разрешение и глубину цвета изображения. Вы также можете задать уровень сжатия и настройки DPI через объект `JpegOptions` для точной настройки качества вывода.
