# Программное изменение слоёв PSD – Добавление слоёв заливки (Java)

Если вы хотите **программно изменить слой PSD**, добавьте слои заливки — один из самых быстрых способов обогатить ваши документы Photoshop, не открывая сам Photoshop. В этом руководстве мы пройдём по лучшим шагам: макет для создания нового PSD, вставка цветовых, градиентных и шаблонных слоев заливки, а затем сохранение результата — всё с использованием Aspose.PSD для Java.

## Быстрые ответы
- **Чего я могу добиться?** Добавить цветовые, градиентные и шаблонные заливки в файл PSD программно.
- **Какая библиотека требуется?** Aspose.PSD для Java (последний релиз).
- **Нужна ли мне лицензия?** Бесплатная пробная версия подходит для тестирования; для продакшна требуется коммерческая лицензия.
- **Сколько времени занимает внедрение?** Около 10‑15 минут для базового примера.
- **Какая версия Java поддерживается?** JDK11 или новее.

## Что такое «программное изменение слоев PSD»?
Программное изменение слоев PSD позволяет использовать код для создания, редактирования или удаления слоев внутри документа Photoshop, обеспечивая полный контроль над процессом проектирования без ручного взаимодействия с пользовательским интерфейсом.

## Зачем добавлять слои заливки с помощью Aspose.PSD?
- **Автоматизация** – Генерация десятков PSD в пакетной задаче.
- **Постоянство** — заменяйте один и тот же цвет, градиент или шаблон во множестве файлов.
- **Скорость** – Пропустить трудоёмкие ручные шаги в Photoshop.
- **Кроссплатформенность** – Работает на любой ОС, поддерживающей Java.

## Предварительные условия
Перед тем как внедриться в код, убедитесь, что у вас есть следующее:

1. **Java Development Kit (JDK)** – Установите JDK11 или новее. Вы можете скачать его с [веб-сайта Oracle](https://www.oracle.com/java/technologies/javase-jdk11-downloads.html).
2. **Aspose.PSD для Java** – загрузить весь контент со страницы официального скачивания [здесь](https://releases.aspose.com/psd/java/).
3. **IDE** – IntelliJ IDEA, Eclipse или любой другой редактор по вашему выбору.
4. **Базовые знания Java** – Знание классов и методов будет ключевым, но руководство всё пошагово.

## Импорт пакетов
Чтобы начать работу с PSD‑файлами, необходимо импортировать соответствующие классы Aspose.PSD:

```java
import com.aspose.psd.fileformats.psd.PsdImage;
import com.aspose.psd.fileformats.psd.layers.filllayers.FillLayer;
import com.aspose.psd.fileformats.psd.layers.fillsettings.FillType;
```

Эти импорты дают вам доступ к объекту `PsdImage` (сам документ) и различным типам `FillLayer`, которые мы будем использовать.

## Как программно изменять слои PSD-файла — пошаговое руководство

### Шаг 1: Настройка папки для сохранения
Определите, где будет сохранён результирующий PSD, чтобы позже легко его найти.

```java
String outputDir = "Your Document Directory";
String outPsdFilePath = outputDir + "output.psd";
```

Замените `"Your Document Directory"` на абсолютный или относительный путь на вашем компьютере.

### Шаг 2: Создание нового документа Photoshop
Создайте пустой холст, который будет содержать слои заливки.

```java
PsdImage psdImage = new PsdImage(100, 100);
```

Параметры `100, 100` означают ширину и высоту в пикселях. При необходимости измените их под требования вашего дизайна.

### Шаг 3: Добавление слоя заливки цветом
Создайте слой сплошной заливки и задайте ему понятное имя.

```java
FillLayer colorFillLayer = FillLayer.createInstance(FillType.Color);
colorFillLayer.setDisplayName("Color Fill Layer");
psdImage.addLayer(colorFillLayer);
```

Позже вы сможете изменить фактический цвет, получив доступ к настройкам заливки слоя (не показано здесь для краткости).

### Шаг 4: Добавление слоя градиентной заливки
Градиентные заливки добавляют глубину и визуальный интерес.

```java
FillLayer gradientFillLayer = FillLayer.createInstance(FillType.Gradient);
gradientFillLayer.setDisplayName("Gradient Fill Layer");
psdImage.addLayer(gradientFillLayer);
```

Не стесняйтесь экспериментировать с линейными или радиальными градиентами через настройки слоя.

### Шаг 5: Добавление слоя заливки узором
Шаблонные заливки позволяют мозаично размещать изображения или текстуры по слою.

```java
FillLayer patternFillLayer = FillLayer.createInstance(FillType.Pattern);
patternFillLayer.setDisplayName("Pattern Fill Layer");
patternFillLayer.setOpacity((byte)50);
psdImage.addLayer(patternFillLayer);
```

Установка непрозрачности в 50 % делает шаблон хорошо сочетающимся с нижележащими слоями.

### Шаг 6: Сохранение PSD-файла
Сохраните изменения на диск.

```java
psdImage.save(outPsdFilePath);
```

Откройте сохранённый файл в Photoshop или любом просмотрщике PSD, чтобы увидеть три новых слоя заливки.

### Шаг 7: Очистка ресурсов
Всегда освобождайте объект `PsdImage`, чтобы освободить нативную память.

```java
psdImage.dispose();
```

## Распространенные проблемы и советы
- **Неверный путь вывода** – убедитесь, что каталог существует и у вас есть права на запись.
- **Использование памяти** – Для очень больших холстов вызываете `psdImage.dispose()` сразу после завершения работы с изображением.
- **Порядок слоев** – По умолчанию добавляются в верхнюю часть стека; `psdImage.insertLayer(layer, index)`, если нужен определенный порядок.
